> 라이브 URL: **https://plant-friends.pages.dev/**

> 근거: `docs/launch-marketing.md`(전략), `docs/brand.md`(톤), `docs/social/youtube-script.md`·`docs/social/share-templates.md`(콘텐츠), `docs/seo-registration.md`(검색등록), `docs/seo-keywords.md`(키워드).

## 0. 시작 전 1회 점검 (D-0, 30분)

본격 가동 전에 아래만 확인하면 됩니다. 막히면 멈추고 점검부터 합니다.

- [ ] `https://plant-friends.pages.dev/` 정상 접속 (질문 3개 → 결과 화면까지 흐름 확인)
- [ ] `https://plant-friends.pages.dev/sitemap.xml` 열림 (XML 목록 보임)
- [ ] `https://plant-friends.pages.dev/robots.txt` 열림 (`Sitemap:` 줄에 실제 도메인)
- [ ] 카톡에 결과 링크 붙여 **OG 미리보기 카드**가 뜨는지 1회 확인 (안 뜨면 `scripts/config.js`의 `KAKAO_JS_KEY`·절대 URL 점검 → 카카오 공유 디버거)
- [ ] 채널별 **UTM** 규칙 확정 (아래 4장) — 링크 만들 때 그대로 붙임

> 추적 도구가 아직 없으면, 최소한 **Search Console·네이버 서치어드바이저·유튜브 스튜디오·쿠팡 파트너스 리포트** 네 곳의 기본 숫자만으로 시작해도 충분합니다.

## 2. 채널별 구체 액션 (요약)

### 2-1. 네이버 밴드 / 카페 (1순위)
- **순서 고정**: ① 가입 후 며칠 활동(댓글·좋아요) → ② 질문 글에 도움 답변 → ③ 경험·팁 글 → 링크는 요청 시 댓글로 1개 이하.
- 주 2~3회, "글 쓰러 가는" 느낌 금지. 한 카페에서 신뢰가 쌓이면 그곳 집중.
- 금지: 같은 글 복붙, 가입 직후 글쓰기, 본문 상단 링크, 효능 단정.

### 2-2. 유튜브 쇼츠 (2순위, 정보 유입)
- 주 1편, 슬라이드+TTS 무촬영 제작(1편 30~60분). 세로 9:16, 자막 48px+, 느린 내레이션.
- 설명란: 라이브 URL + `/guide.html` + 타임스탬프 + 해시태그 8~12개. 쿠팡 링크 상단 금지.
- 후킹 3초 A/B(`ready-to-post.md` 대본의 A/B/C 문장)로 조회 개선.

### 2-3. 검색 (2순위, 누적 유입)
- 1주차 내 네이버·구글 등록 완료. 롱테일(`OO 키우는 법/물주기/햇빛`)이 핵심 누적 유입원.
- 유튜브·밴드 글 키워드를 사이트 키워드(`docs/seo-keywords.md`)와 일치시켜 시그널 모으기.

### 2-4. 카카오톡 (상시, 공유 루프)
- 결과 페이지 공유 버튼 활용. 메시지는 **한두 줄 + 링크**(길게 금지).
- 단체방 도배 금지 — 개별 대화 중심. OG 카드가 떠야 클릭률 상승.

### 2-5. 인스타·스레드 (비주력 보조)
- 자원 최소. 쇼츠 발행 시 같은 슬라이드로 보조 노출만(`ready-to-post.md` 짧은 글 1종).

## 3. KPI (2주 측정)

| 지표 | 정의 | 측정 방법 | 2주 가이드 목표 |
|---|---|---|---|
| **유입(세션)** | 사이트 방문 수 | Search Console + 채널별 UTM | 채널별 추이 우상향, 채널 ≥3개 활성 |
| **추천 완료율** | 질문 시작 → 결과 도달 | quiz→result 이벤트 | **60%+** |

## 4. UTM 규칙 (링크에 붙여 채널 구분)

기본형: `https://plant-friends.pages.dev/?utm_source=__&utm_medium=__&utm_campaign=launch2w`

| 채널 | utm_source | utm_medium | 예시 |
|---|---|---|---|
| 네이버 밴드 | `band` | `community` | `?utm_source=band&utm_medium=community&utm_campaign=launch2w` |
| 네이버 카페 | `cafe` | `community` | `?utm_source=cafe&utm_medium=community&utm_campaign=launch2w` |
| 유튜브 쇼츠 | `youtube` | `shorts` | `?utm_source=youtube&utm_medium=shorts&utm_campaign=launch2w` |
| 카카오톡 | `kakao` | `share` | `?utm_source=kakao&utm_medium=share&utm_campaign=launch2w` |
| 인스타/스레드 | `instagram` | `social` | `?utm_source=instagram&utm_medium=social&utm_campaign=launch2w` |

> 주의: **카톡 공유 메시지에는 깔끔한 기본 URL**(쿼리 없는 `https://plant-friends.pages.dev/`)을 권장합니다 — OG 미리보기·신뢰감 우선. UTM은 밴드/카페/유튜브 설명란처럼 본인이 붙여넣는 링크에만 사용합니다.

## 5. 검색 등록 즉시 할 일 (요약)

> 상세 단계·메뉴 경로는 **`docs/seo-registration.md`** 참조. 핵심만:

1. **네이버 서치어드바이저** (시니어 주 채널 → 가장 먼저)
   - `https://searchadvisor.naver.com` 로그인 → 사이트 등록 `https://plant-friends.pages.dev/`
   - 사이트 소유 확인(HTML 태그 또는 파일) → **요청 > 사이트맵 제출**에 `https://plant-friends.pages.dev/sitemap.xml`
2. **구글 Search Console**
   - `https://search.google.com/search-console` 로그인 → 속성 추가(`https://plant-friends.pages.dev/`)
   - 소유 확인 → **색인 생성 > Sitemaps**에 `sitemap.xml` 제출 → URL 검사로 `/`·`/guide.html` 색인 요청
3. (보조) **빙 웹마스터** — Search Console에서 가져오기로 간단 등록 가능.

> 제출 후 색인은 수일~수주 걸립니다. D7·D8에 진행 상황 확인, 미색인 페이지 재요청.
