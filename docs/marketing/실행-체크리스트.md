# 7일 실행 체크리스트 — 우리집 초록친구

> 라이브 주소: **https://plant-friends.pages.dev/**
> 하루 **10~20분**이면 충분합니다. 위에서부터 차례대로, 하루에 한 칸씩만 하세요.
> 복붙할 글은 모두 **`docs/marketing/복붙-게시물.md`** 에 완성되어 있습니다. 거기서 복사해 붙여넣기만 하면 됩니다.
> 톤 원칙: 따뜻하게, 존댓말로. **도배·과장·허위효능 금지.** 광고처럼 보이면 막힙니다.

---

## 시작하기 전에 (딱 한 번, 5분)

아래 주소 3개를 인터넷 창에 한 번씩 쳐서 잘 열리는지만 확인하세요. 안 열리면 그날은 멈추고 점검부터 합니다.

- [ ] 사이트가 열리나요? → `https://plant-friends.pages.dev/`
- [ ] 사이트맵이 열리나요? (글자 목록이 보이면 정상) → `https://plant-friends.pages.dev/sitemap.xml`
- [ ] 케어가이드가 열리나요? → `https://plant-friends.pages.dev/guide.html`
- [ ] 읽을거리(블로그 글 모음)가 열리나요? → `https://plant-friends.pages.dev/articles.html`

> **메모 칸 만들기**: 종이 한 장이나 휴대폰 메모장에 "네이버 비밀번호 / 구글 비밀번호 / 가입한 카페 이름" 을 적어 두세요. 매일 다시 찾지 않아도 됩니다.

## Day 1 (월) — 네이버에 사이트 등록하기 · 약 15분

> 네이버는 우리 손님(50~60대)이 가장 많이 쓰는 검색입니다. 그래서 제일 먼저 합니다.

- [ ] **[검색등록]** 인터넷 창에 `searchadvisor.naver.com` 입력 → **[네이버 로그인]** 버튼 클릭
- [ ] 화면 위쪽 **[웹마스터 도구]** 클릭 → 가운데 입력칸에 `https://plant-friends.pages.dev/` 붙여넣고 **[추가]** 버튼 클릭
- [ ] "사이트 소유 확인" 화면이 나오면 → **[HTML 태그]** 방식 선택 → 화면에 나온 글자(메타태그)를 복사해 두기
  - 이 메타태그를 사이트에 넣는 작업은 개발 담당(또는 자녀)에게 부탁하세요. 상세 방법은 `docs/seo-registration.md` 에 있습니다.
- [ ] 소유 확인이 끝나면 → 왼쪽 메뉴 **[요청] > [사이트맵 제출]** 클릭 → 입력칸에 `sitemap.xml` 만 적고 **[확인]** 클릭
- [ ] 끝! (검색에 실제로 뜨기까지는 며칠~몇 주 걸립니다. 조급해하지 마세요.)

> **주의**: 소유 확인이 잘 안 되면 그날은 거기까지만 하고, 다음 날 자녀나 개발 담당에게 메타태그 넣기를 부탁한 뒤 이어서 하세요. 억지로 진행하지 않아도 됩니다.

---

## Day 2 (화) — 구글에 사이트 등록하기 · 약 15분

- [ ] **[검색등록]** 인터넷 창에 `search.google.com/search-console` 입력 → **[구글 로그인]**
- [ ] **[속성 추가]** 클릭 → "URL 접두어" 칸에 `https://plant-friends.pages.dev/` 붙여넣고 **[계속]** 클릭
- [ ] 소유 확인 화면 → **[HTML 태그]** 방식의 글자를 복사 (Day1과 같은 방식, 개발 담당에게 부탁 가능)
- [ ] 확인되면 → 왼쪽 메뉴 **[Sitemaps]** 클릭 → 입력칸에 `sitemap.xml` 적고 **[제출]** 클릭
- [ ] 왼쪽 위 **[URL 검사]** 칸에 `https://plant-friends.pages.dev/` 붙여넣고 → **[색인 생성 요청]** 클릭
- [ ] 한 번 더, **[URL 검사]** 칸에 `https://plant-friends.pages.dev/guide.html` 붙여넣고 → **[색인 생성 요청]** 클릭
- [ ] 한 번 더, **[URL 검사]** 칸에 `https://plant-friends.pages.dev/articles.html` 붙여넣고 → **[색인 생성 요청]** 클릭 (새로 쓴 읽을거리 글이 검색에 잡히게)

> **주의**: 색인(검색에 등록되는 것)은 시간이 걸립니다. 오늘 안 떠도 정상입니다.

---

## Day 3 (수) — 가족·친구에게 카톡으로 알리기 · 약 10분

> 가장 쉽고, 가장 따뜻한 첫걸음입니다.

- [ ] **[카톡]** 자녀 또는 친한 사람 **2~3명에게 개별로** 카톡 보내기
  - 복붙할 글: `복붙-게시물.md` 의 **"2. 카톡 공유 메시지"** 에서 골라 쓰기
  - 원하면 카드 이미지 `public/marketing/share-card-main.png` 를 함께 첨부(공기정화 주제면 `share-card-air.png`, 반려동물 주제면 `share-card-petsafe.png`). 파일은 `public/marketing/` 폴더에 있습니다.
- [ ] 보낼 때 링크 `https://plant-friends.pages.dev/` 아래에 **그림 카드(미리보기)** 가 뜨는지 확인 (뜨면 잘 된 것)
- [ ] 받은 사람에게 "한번 해보고 어땠는지 알려줘" 라고 가볍게 덧붙이기

> **주의**: 단체 채팅방에 똑같은 글을 여러 번 보내지 마세요(도배 금지). **한 사람 한 사람에게** 보내는 것이 훨씬 좋습니다.

---

## Day 4 (목) — 네이버 밴드/카페 1곳 가입하기 · 약 15분

> 오늘은 **가입만** 합니다. 글은 아직 쓰지 않습니다. 며칠 분위기를 보는 것이 예의입니다.

- [ ] **[밴드/카페]** 네이버에서 "식물 키우기", "반려식물", "원예" 같은 말로 검색
- [ ] **활동이 많고 사람이 많은 곳 1곳**만 골라 **[가입하기]** 클릭
- [ ] 가입 인사 칸이 있으면 짧게: "안녕하세요, 식물 처음 키우는 사람입니다. 잘 배우겠습니다 :)"
- [ ] 그 카페/밴드의 **[공지사항]** 을 한 번 읽어보기 (홍보·링크 규정 확인 — 이게 제일 중요합니다)

> **주의**: 가입하자마자 글 쓰거나 링크 올리면 강제 탈퇴될 수 있습니다. **3일은 눈팅(구경)** 만 하세요.

## Day 5 (금) — 유튜브 쇼츠 1편 만들기 (선택) · 약 30~60분

> 시간이 없으면 이 날은 건너뛰고 Day 6으로 가도 됩니다. 여유가 있을 때 만드세요.

- [ ] **[유튜브]** 대본·제목·설명란은 `복붙-게시물.md` 의 **"3. 유튜브 쇼츠"** 에 완성되어 있음
- [ ] 거기 적힌 **"무촬영 제작 순서"** 대로 슬라이드 + 음성(TTS)으로 만들기 (얼굴·촬영 필요 없음)
- [ ] 다 만들면 유튜브에 업로드 → **제목**과 **설명란**을 복붙 → **[게시]**
- [ ] 썸네일은 만들어 둔 `public/marketing/youtube-thumb.png` 를 지정 (파일 위치: `public/marketing/` 폴더)
- [ ] 업로드할 때 "Shorts(쇼츠)" 로 올라가는지 확인 (세로 영상이면 자동으로 됩니다)

> **주의**: 썸네일·제목에 "다 낫는다, 미세먼지 싹 없앤다" 같은 과장은 절대 금지입니다.

---

## Day 6 (토) — 가입한 카페에서 댓글로 인사 나누기 · 약 15분

> 아직 내 글을 올리는 날이 아닙니다. **남의 글에 따뜻한 댓글**을 다는 날입니다.

- [ ] **[밴드/카페]** 어제 가입한 곳에서, 식물 고민 글 **2~3개**에 도움 댓글 달기
  - 복붙할 글: `복붙-게시물.md` 의 **"1. 밴드/카페 글 → 글② 질문답변(댓글형)"**
  - 그대로 붙이지 말고 **내 경험을 한두 줄** 더해 자연스럽게
- [ ] 링크는 달지 마세요. 누가 "어디서 알아봤어요?" 물으면 그때만 댓글로 살짝 안내

> **주의**: 댓글마다 똑같은 문장 복붙 금지. 사람마다 다르게, 진짜 대화처럼.

---

## Day 7 (일) — 첫 게시글 1개 올리기 + 한 주 돌아보기 · 약 20분

> 며칠 활동했으니 이제 자연스럽게 내 글 1개를 올려도 됩니다.

- [ ] **[밴드/카페]** 가입한 곳에 **경험 나눔 글 1개** 올리기
  - 복붙할 글: `복붙-게시물.md` 의 **"1. 밴드/카페 글 → 글① 경험나눔형"**
  - 내 식물 사진 1장 같이 올리면 더 좋습니다
  - 링크는 본문에 1개 이하, 가능하면 댓글에 (카페 규정 확인)
- [ ] **[읽을거리 공유]** 관심사가 맞는 곳 **딱 한 곳에 한 번만** 우리 읽을거리 글을 자연스럽게 소개 (도배 금지)
  - 카페/밴드 댓글이나 짧은 글: `복붙-게시물.md` 의 **"5. (대안) 읽을거리 글 공유 멘트"** 사용 → `https://plant-friends.pages.dev/articles.html`
  - 또는 친한 분께 개별 카톡: `복붙-게시물.md` 의 **"2-4. 주제 글 공유"** (공기정화면 air 글, 반려동물이면 pet-safe 글). 카드 이미지(`public/marketing/share-card-air.png` 또는 `share-card-petsafe.png`) 함께 보내면 좋습니다.
- [ ] **[점검]** 네이버·구글에 들어가 사이트가 검색에 떴는지 한 번 확인 (안 떴으면 며칠 더 기다리기)
- [ ] **[점검]** 이번 주에 카톡 보낸 사람 중 사이트를 해본 사람이 있는지 확인
- [ ] 다음 주 계획: **가장 반응이 좋았던 채널 1곳**(카톡/카페/유튜브 중)에 집중하기로 마음먹기

> **주의**: 한 번에 여러 카페에 같은 글을 올리지 마세요. **한 곳에 정성껏 1개**가 백 번의 도배보다 낫습니다.

## 매일 지킬 안전수칙 (한눈에)

1. **도배 금지** — 같은 글을 여러 곳/여러 번 올리지 않기.
2. **과장·허위 금지** — "다 낫는다, 미세먼지 제거" 같은 단정 표현 쓰지 않기.
3. **링크는 살짝** — 한 글에 1개 이하, 본문 맨 위 금지, 가능하면 댓글로.
4. **먼저 도움** — 팔려고 하지 말고, 도움이 되면 자연스럽게 따라옵니다.
5. **천천히** — 하루 한 칸이면 충분합니다. 무리하지 마세요.

> 자세한 2주 일정·성과 측정은 `docs/marketing/launch-push.md` 에 있습니다.
