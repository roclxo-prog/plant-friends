## 1. 네이버 밴드 / 카페 글 3종

> **공통 주의**: 가입 직후엔 쓰지 마세요(며칠 활동 후). 한 글에 링크는 1개 이하, 본문 맨 위 금지. 같은 글을 여러 카페에 복붙하지 말고, **내 경험을 한두 줄 바꿔** 다르게 쓰세요.

### 글 ① — 경험 나눔형 (게시글로 올리기 / 가장 자연스러움)

> **붙여넣는 곳**: 가입한 밴드·카페에 새 게시글. 내 식물 사진 1장 함께 올리면 더 좋습니다.
> **주의**: 링크는 본문에 넣지 말고, 누가 물어보면 댓글로 안내(카페 규정 확인).

```
제목: 처음 키운 산세베리아, 반년째 잘 살아요 :)

안녕하세요. 식물은 처음이라 늘 죽이기만 했는데,
물을 자주 안 줘도 되는 산세베리아는 반년째 잘 자라네요.
빛이 약한 거실에서도 괜찮았어요.

저처럼 처음이신 분들은 물 자주 안 줘도 되는 걸로 시작하시면
마음이 한결 편하더라고요.
혹시 우리집에 뭐가 맞을지 모르겠으면, 질문 몇 개 답하면
골라주는 곳도 있더라고요. 필요하신 분 계시면 댓글로 알려드릴게요. 🌱
```

> 누가 "어디서 알아봤어요?" 물으면 댓글로:
> `우리집에 맞는 식물 1분 만에 찾기 → https://plant-friends.pages.dev/ (가입·사진 없어요)`

### 글 ② — 질문답변형 (남의 고민 글에 다는 댓글)

> **붙여넣는 곳**: "어떤 식물을 키울까요?" 같은 고민 글의 댓글.
> **주의**: 댓글마다 똑같이 복붙 금지. 사람마다 다르게, 진짜 대화처럼.

```
저도 처음에 같은 고민이었어요.
빛이 약한 방이면 산세베리아나 스킨답서스가 잘 맞아요. 물도 자주 안 줘도 돼요.
저는 질문 3개 답하면 맞는 식물 골라주는 곳에서 스킨답서스가 나왔는데
지금까지 잘 키우고 있어요. 가입도 사진도 필요 없더라고요 :)
필요하시면 알려드릴게요.
```

> 카페 규정이 링크를 허용하면 한 줄 덧붙이기:
> `→ https://plant-friends.pages.dev/`

### 글 ③ — 정보공유형 (케어 팁 게시글)

> **붙여넣는 곳**: 신뢰가 좀 쌓인 카페에 정보 나눔 게시글.
> **주의**: 효능 단정 금지. "이렇게 하니 저는 잘 됐어요" 정도의 경험 톤으로.

```
제목: 식물 물주기, 저는 이렇게 하니 안 죽더라고요

물을 정해진 날짜에 주는 것보다, 흙을 손가락으로 눌러보고
말랐을 때 한 컵 정도만 주니까 훨씬 잘 자라요.
잎이 조금 시들어도 며칠 말려주면 다시 괜찮아지더라고요.

식물별로 물주기·햇빛을 정리해 둔 글도 봤는데 도움이 됐어요.
처음이신 분들 너무 어렵게 생각 안 하셔도 돼요. 천천히 같이 키워봐요. 🌿
```

> 링크 요청·허용 시:
> `물 적게 줘도 되는 식물 7가지 → https://plant-friends.pages.dev/articles/easy-low-water-plants.html`

## 2. 카카오톡 공유 메시지 3종

> **공통 주의**: 한두 줄 + 링크가 가장 잘 열립니다. 단체방 도배 금지, **개별 대화** 중심. 링크는 깔끔한 기본 주소(`https://plant-friends.pages.dev/`)를 쓰면 미리보기 카드가 예쁘게 뜹니다.
> **이미지 첨부**: 글만 보내도 되지만, 카드 이미지를 함께 보내면 눈에 잘 띕니다. `public/marketing/share-card-main.png` 를 첨부하세요(공기정화 주제 글이면 `share-card-air.png`, 반려동물 주제 글이면 `share-card-petsafe.png`). 파일은 모두 **`public/marketing/` 폴더**에 있습니다.

### 2-2. 친구·또래에게

## 3. 유튜브 쇼츠 60초 — 대본 + 제목 + 설명란 (완성본)

> **주의**: 얼굴 촬영 필요 없습니다. 슬라이드 + 음성(TTS)으로 만듭니다. 과장·허위 효능 표현 금지.

### 3-1. 제목 3안 (하나 고르기)

```
1안: 처음 키워도 안 죽는 실내 식물 3가지 (50대 이후 추천)
2안: 물 자주 깜빡해도 잘 사는 식물 3가지
3안: 빛 안 드는 방에서도 잘 자라는 식물 3가지
```

### 3-2. 장면별 대본 (60초)

| 시간 | 화면(슬라이드) | 내레이션(존댓말) |
|---|---|---|
| 0~3초 | 큰 글씨 한 줄 + 잎 사진 | "식물, 사다가 금방 시들어서 속상하셨지요? 처음이라도 안 죽이는 식물부터 알려드릴게요." |
| 3~12초 | 산세베리아 사진 | "첫 번째는 산세베리아예요. 물을 자주 깜빡해도 잘 견뎌요. 빛이 약한 방에서도 괜찮아요." |
| 12~22초 | 스킨답서스 사진 | "두 번째는 스킨답서스예요. 흙이 마르면 한 컵만 주시면 돼요. 잎도 쑥쑥 늘어나요." |
| 22~32초 | 금전수 사진 | "세 번째는 금전수예요. 손이 거의 안 가서 선물로도 좋아요." |
| 32~45초 | "왜 이 친구들?" 자막 + 물 한 컵 그림 | "공통점이 있어요. 물을 자주 안 줘도 되고, 빛이 약한 집에서도 자라요. 그래서 처음 키우시는 분께 잘 맞아요." |
| 45~57초 | 사이트 화면 캡처 + "질문 3개 1분" 자막 | "우리집에 어떤 식물이 맞는지는, 아래 설명란 링크에서 질문 세 개만 답하면 1분 만에 찾아드려요. 가입도, 사진도 필요 없어요." |
| 57~60초 | 로고 + "실수해도 괜찮아요" | "실수해도 괜찮아요. 천천히 같이 키워봐요." |

### 3-3. 설명란 (그대로 복붙)

> **붙여넣는 곳**: 유튜브 업로드 화면의 "설명" 칸.

```
처음 키우셔도 잘 사는 실내 식물 3가지를 골라드렸어요.
물을 자주 안 줘도 되고, 빛이 약한 집에서도 잘 자라는 친구들이에요.

▶ 우리집에 맞는 식물 1분 만에 찾기 (질문 3개, 가입·사진 없음)
https://plant-friends.pages.dev/

▶ 식물별 키우는 법 모음
https://plant-friends.pages.dev/guide.html

▶ 거실 공기정화에 좋은 식물 5가지 (읽을거리)
https://plant-friends.pages.dev/articles/air-purifying-plants.html

0:00 시작
0:03 산세베리아
0:12 스킨답서스
0:22 금전수
0:32 왜 초보에게 맞을까요
0:45 우리집 맞춤 추천 받는 법

#키우기쉬운식물 #실내식물추천 #초보식물 #공기정화식물 #식물추천 #산세베리아 #스킨답서스 #금전수 #50대취미 #실버원예
```

### 3-4. 무촬영 제작 순서 (슬라이드 + 음성, 1편 30~60분)

1. **사진 준비**: 라이선스 안전한 식물 사진만 사용(`docs/asset-licenses.md`). 사이트의 식물 사진(`public/plants/` — 예: `sansevieria.jpg`, `scindapsus.jpg`, `zamioculcas.jpg`)을 그대로 써도 됩니다.
2. **슬라이드 만들기**: 위 표대로 1장면 = 1슬라이드. 세로 9:16(1080×1920). 자막 48px 이상, **크림 배경(#F5F0E1) + 잉크 글자(#1B1B1B)**.
3. **음성(TTS)**: 네이버 클로바더빙·타입캐스트 등으로 위 내레이션을 읽히기. 속도는 약간 느리게(시니어 배려).
4. **편집**: CapCut 또는 캔바(Canva) 무료 템플릿에 슬라이드 + 음성 + 전체 자막 얹기. BGM은 저작권 프리, 볼륨 낮게.
5. **자막 필수**: 소리 없이 보는 분을 위해 전체 자막을 꼭 넣기.
6. **썸네일**: 만들어 둔 썸네일 `public/marketing/youtube-thumb.png`("초보도 안 죽이는 식물 추천", 1280×720)를 업로드 시 썸네일로 지정하세요. 직접 만들 경우 큰 글씨 + 식물 사진, 과장 표현 금지. (파일 위치: `public/marketing/` 폴더)

> 후킹 3초 A/B 대안: (A) "식물, 사다가 금방 시들어서 속상하셨지요?" / (B) "물을 자주 깜빡하셔도 잘 사는 식물이 있어요." / (C) "빛이 잘 안 드는 방에서도 잘 자라는 식물 3가지예요."

## 5. 블로그/카페 정보글 1편 (긴 글 / 읽을거리 글로 연결)

> **붙여넣는 곳**: 블로그 또는 신뢰가 쌓인 카페의 정보 게시판.
> **주의**: 정보가 먼저, 링크는 맨 끝에 1회만. **효능 단정·과장 금지**("미세먼지 다 없앤다" 류 금지).

```
제목: 거실에 두기 좋은, 키우기 쉬운 실내 식물 5가지 (50대 이후 초보에게)

거실에 초록 하나 두고 싶은데, 자꾸 죽여서 망설이셨지요?
저도 그랬어요. 그런데 '잘 안 죽는 친구'부터 시작하니 마음이 한결 편해지더라고요.

식물을 고를 때 저는 이 세 가지만 봤어요.
① 물을 자주 안 줘도 되는지
② 빛이 약한 집에서도 사는지
③ 손이 적게 가는지

이 기준으로 골라본 다섯 친구를 소개할게요.

1) 산세베리아
- 물을 깜빡해도 잘 견뎌요. 빛 약한 방도 괜찮아요. 흙이 바싹 마르면 한 컵.

2) 스킨답서스
- 잎이 쑥쑥 늘어나는 재미가 있어요. 흙이 마르면 물 한 컵.

3) 금전수
- 손이 거의 안 가서 선물로도 좋아요. 물은 아주 가끔만.

4) 스파티필름
- 잎이 축 처지면 "물 주세요" 신호예요. 알아보기 쉬워요.

5) 테이블야자
```
