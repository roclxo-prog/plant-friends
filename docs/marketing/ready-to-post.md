## 1. 네이버 밴드/카페 소개 글 3종 (도배 아님, 경험·질문답변 톤)

> **사용법**: 같은 글을 여러 곳에 복붙하지 마세요. 아래를 뼈대로 **본인 경험을 한두 줄 바꿔** 다르게 씁니다. 링크는 한 글에 1개 이하, 본문 상단 지양. 가입 직후 글쓰기 금지(며칠 활동 후).

### 글 ① — 경험 나눔형 (게시글, 가장 자연스러움)
```
제목: 처음 키운 산세베리아, 반년째 잘 살아요 :)

안녕하세요. 식물은 처음이라 늘 죽이기만 했는데,
물을 자주 안 줘도 되는 산세베리아는 반년째 잘 자라네요.
빛이 약한 거실에서도 괜찮았어요.

저처럼 처음이신 분들은 물 자주 안 줘도 되는 걸로 시작하시면
마음이 한결 편하더라고요.
혹시 우리집에 뭐가 맞을지 모르겠으면, 질문 몇 개 답하면
골라주는 곳도 있더라고요. 필요하신 분 계시면 댓글로 알려드릴게요.
```
> 링크는 댓글 요청 시: `우리집에 맞는 식물 1분 만에 찾기 → https://plant-friends.pages.dev/ (가입·사진 없음)`

### 글 ② — 질문 글에 다는 답변 (댓글형)
```
저도 처음에 같은 고민이었어요.
빛이 약한 방이면 산세베리아나 스킨답서스가 잘 맞아요. 물도 자주 안 줘도 돼요.
저는 질문 3개 답하면 맞는 식물 골라주는 곳에서 스킨답서스가 나왔는데
지금까지 잘 키우고 있어요. 가입도 사진도 필요 없더라고요 :)
필요하시면 알려드릴게요.
```
> 카페 규정이 링크를 허용하면 한 줄 덧붙임: `→ https://plant-friends.pages.dev/`

### 글 ③ — 케어 팁 나눔형 (정보 제공 게시글)
```
제목: 식물 물주기, 저는 이렇게 하니 안 죽더라고요

물을 정해진 날짜에 주는 것보다, 흙을 손가락으로 눌러보고
말랐을 때 한 컵 정도만 주니까 훨씬 잘 자라요.
잎이 조금 시들어도 며칠 말려주면 다시 괜찮아지더라고요.

식물별로 물주기·햇빛을 정리해 둔 글도 봤는데 도움이 됐어요.
처음이신 분들 너무 어렵게 생각 안 하셔도 돼요. 천천히 같이 키워봐요.
```
> 링크는 요청/허용 시: `식물별 키우는 법 모음 → https://plant-friends.pages.dev/guide.html`

## 3. 유튜브 쇼츠 60초 대본 — "초보도 안 죽이는 식물 추천"

> 제목(클릭베이트 아님): **"처음 키워도 안 죽는 실내 식물 3가지 (50대 이후 추천)"**
> 길이 약 55~60초. 정직하고 또렷하게, 존댓말.

### 3-1. 장면별 대본

| 시간 | 화면(슬라이드) | 내레이션(존댓말) |
|---|---|---|
| **0~3초 (후킹)** | 큰 글씨 한 줄 + 잎 사진 | "식물, 사다가 금방 시들어서 속상하셨지요? 처음이라도 안 죽이는 식물부터 알려드릴게요." |
| 3~12초 | 산세베리아 사진 | "첫 번째는 산세베리아예요. 물을 자주 깜빡해도 잘 견뎌요. 빛이 약한 방에서도 괜찮아요." |
| 12~22초 | 스킨답서스 사진 | "두 번째는 스킨답서스예요. 흙이 마르면 한 컵만 주시면 돼요. 잎도 쑥쑥 늘어나요." |
| 22~32초 | 금전수 사진 | "세 번째는 금전수예요. 손이 거의 안 가서 선물로도 좋아요." |
| 32~45초 (가치) | "왜 이 친구들?" 자막 + 물 한 컵 그림 | "공통점이 있어요. 물을 자주 안 줘도 되고, 빛이 약한 집에서도 자라요. 그래서 처음 키우시는 분께 잘 맞아요." |
| 45~57초 (CTA) | 사이트 화면 캡처 + "질문 3개 1분" 자막 | "우리집에 어떤 식물이 맞는지는, 아래 설명란 링크에서 질문 세 개만 답하면 1분 만에 찾아드려요. 가입도, 사진도 필요 없어요." |
| 57~60초 | 로고 + "실수해도 괜찮아요" | "실수해도 괜찮아요. 천천히 같이 키워봐요." |

**후킹 3초 A/B 대안**
- A: "식물, 사다가 금방 시들어서 속상하셨지요?"
- B: "물을 자주 깜빡하셔도 잘 사는 식물이 있어요."
- C: "빛이 잘 안 드는 방에서도 잘 자라는 식물 3가지예요."

### 3-2. 영상 설명란 (복붙용)
```
처음 키우셔도 잘 사는 실내 식물 3가지를 골라드렸어요.
물을 자주 안 줘도 되고, 빛이 약한 집에서도 잘 자라는 친구들이에요.

▶ 우리집에 맞는 식물 1분 만에 찾기 (질문 3개, 가입·사진 없음)
https://plant-friends.pages.dev/

▶ 식물별 키우는 법 모음
https://plant-friends.pages.dev/guide.html

0:00 시작
0:03 산세베리아
0:12 스킨답서스
0:22 금전수
0:32 왜 초보에게 맞을까요
0:45 우리집 맞춤 추천 받는 법

#키우기쉬운식물 #실내식물추천 #초보식물 #공기정화식물 #식물추천 #산세베리아 #스킨답서스 #금전수 #50대취미 #실버원예
```
> 쿠팡 링크는 설명 최상단 금지. 필요 시 "구매 링크 포함, 일부 수수료를 받습니다" 고지 후 하단에만.

### 3-3. 무촬영 제작법 (슬라이드 + TTS)
직접 촬영·얼굴 노출 없이 만듭니다. 1편 ≈ 30~60분.
1. **이미지**: 라이선스 안전한 식물 사진만(`docs/asset-licenses.md`). 사이트 식물 사진 재사용 가능.
2. **슬라이드**: 위 표대로 1장면=1슬라이드, 세로 9:16(1080×1920). 자막 48px+, 크림 배경(`#F5F0E1`)+잉크 글자(`#1B1B1B`).
3. **음성(TTS)**: 자연스러운 한국어 TTS(네이버 클로바더빙, 타입캐스트 등). 말 속도 약간 느리게(시니어 배려).
4. **편집**: CapCut/캔바 무료 템플릿에 슬라이드+음성+전체 자막. BGM은 저작권 프리, 볼륨 낮게.
5. **자막 필수**: 소리 없이 보는 시청자 위해 전체 자막.
6. **썸네일**: 큰 글씨 "안 죽는 식물 3가지" + 식물 사진. 과장 표현 금지.

> 시리즈 확장: "물 자주 깜빡해도 사는 식물", "빛 안 드는 방 식물", "공기 맑게 해주는 식물 3가지", "선물하기 좋은 화분", 식물별 1분 케어("산세베리아 물주기" 등) → `guide.html`·식물 상세와 키워드 연결.

## 5. 블로그/카페 정보글 개요 — "거실에 두기 좋은 공기정화 식물 5"

> 카페·블로그용 롱폼 1편 뼈대. 정보가 먼저, 도구는 자연스럽게 1회만 연결. 효능 단정·과장 금지("미세먼지 다 없앤다" 류 금지).

**제목(안)**: 거실에 두기 좋은, 키우기 쉬운 실내 식물 5가지 (50대 이후 초보에게)

**구성**
1. **들어가며** — "거실에 초록 하나 두고 싶은데 자꾸 죽여서 망설이셨지요?" 공감 한 단락. 존댓말.
2. **고르는 기준 3가지** — ① 물 자주 안 줘도 되는지 ② 빛 약한 집에서도 사는지 ③ 손이 적게 가는지.
3. **식물 5종(각 항목 동일 틀: 특징 / 물주기 / 빛 / 한 줄 팁)**
   - 산세베리아 → 상세: https://plant-friends.pages.dev/plants/sansevieria.html
   - 스킨답서스 → https://plant-friends.pages.dev/plants/scindapsus.html
   - 금전수 → https://plant-friends.pages.dev/plants/zamioculcas.html
   - 스파티필름 → https://plant-friends.pages.dev/plants/spathiphyllum.html
   - 테이블야자 → https://plant-friends.pages.dev/plants/parlor_palm.html
4. **물주기 공통 팁** — "흙을 손가락으로 눌러보고 마르면 한 컵." (밴드글 ③ 재활용)
5. **공기정화 관련** — 단정 대신 사실 위주로 부드럽게("실내 분위기와 습도에 도움을 준다고 알려져 있어요" 수준, 의학적 효능 단정 금지).
6. **마무리 + 도구 연결(1회)** — "어떤 친구가 우리집에 맞을지 헷갈리시면, 질문 3개로 1분이면 골라드려요. 가입도 사진도 필요 없어요." → https://plant-friends.pages.dev/
   - 식물별 키우는 법 모음: https://plant-friends.pages.dev/guide.html

> 키워드(자연스럽게, 스터핑 금지): 거실 식물 추천, 공기정화 식물, 키우기 쉬운 실내 식물, 초보 식물(`docs/seo-keywords.md`).
