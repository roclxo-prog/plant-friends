# 구글 애드센스 심사 체크리스트

> 애드센스는 **보조 수익원**입니다(주 수익은 쿠팡 파트너스).
> 광고는 **콘텐츠 페이지 하단에만** 들어갑니다. 결과·도구 화면에는 절대 넣지 않습니다.
>
> 아래는 심사 통과를 위한 항목 + **현재 충족 여부 점검(2026-06-06 기준)** 입니다.

---

## 1. 심사 통과 핵심 항목 + 현재 상태

| 항목 | 요구사항 | 현재 상태 | 비고 |
|---|---|---|---|
| 실제 작동하는 도구 | 방문자가 쓸 수 있는 기능이 실제 동작 | ✅ 충족 | 환경 질문 3개 → 식물 3종 추천(quiz/result) 작동 |
| 케어가이드 콘텐츠 분량 | 의미 있는 글 10편 이상, 각 1,000자+ | ⚠️ 확인 필요 | 식물 페이지 10종 + guide 존재. **각 페이지 본문이 1,000자 이상인지 글자 수 점검 필요.** 현재 12종 중 상추·바질 상세 페이지 없음(아래 참고) |
| 개인정보처리방침 | 명시 페이지 존재 | ✅ 충족 | `/privacy.html` |
| 소개(About) | 운영 주체·목적 안내 | ✅ 충족 | `/about.html` |
| 문의(Contact) | 연락 수단 안내 | ✅ 충족 | `/contact.html` (이메일은 config.js로 주입) |
| sitemap.xml | 검색엔진 색인용 사이트맵 | ❌ 미충족 | **현재 없음. 생성 필요(아래 4번).** |
| robots.txt | 크롤러 허용 + 사이트맵 위치 | ❌ 미충족 | **현재 없음. 생성 필요(아래 4번).** |
| Google Search Console | 사이트 등록·색인 요청 | ❌ 미완(운영자 작업) | 배포 후 Search Console에 도메인 등록 + 사이트맵 제출 |
| 모바일 반응형 | 모바일에서 깨짐 없이 표시 | ✅ 충족(추정) | `meta viewport` 모든 페이지에 존재. 실기기 확인 권장 |
| 이미지 저작권 | CC0 등 사용 가능한 이미지만 | ⚠️ 확인 필요 | `docs/asset-licenses.md` 와 실제 `public/plants/*.jpg` 라이선스 대조 필요 |
| 충분한 페이지 수 | 빈 페이지·공사중 없음 | ✅ 대체로 충족 | 핵심 페이지 모두 콘텐츠 채워짐 |

> 정책 페이지 "3종"(개인정보처리방침·소개·문의)은 모두 존재합니다.

### 분량 점검이 필요한 이유
- 애드센스는 "가치 있는 콘텐츠"를 봅니다. 식물 페이지가 짧으면 반려될 수 있습니다.
- **권장**: 식물 10종 페이지 + guide 가 각각 1,000자 이상인지 확인하고, 부족하면 케어 팁·계절 관리·자주 묻는 질문을 보강.
- `plants.json` 에는 식물 **12종**이 있으나 상세 HTML은 **10종**(상추 lettuce·바질 basil 없음)입니다.
  심사 콘텐츠 양을 늘리려면 이 2종 페이지 추가가 도움이 됩니다. *(콘텐츠 작성은 다른 에이전트 영역 — 여기선 지적만)*

## 2. 광고 코드는 어디에 넣나 (이미 구현됨 — 운영자는 ID만)

직접 광고 코드를 HTML에 붙일 필요 **없습니다.** 다음 한 줄이면 됩니다.

1. `scripts/config.js` 의
   ```js
   ADSENSE_CLIENT_ID: "여기에_애드센스_ID",
   ```
   를 **실제 애드센스 게시자 ID**(예: `ca-pub-XXXXXXXXXXXXXXXX`)로 교체합니다.
2. 끝. 코드가 자동으로:
   - placeholder면 광고 스크립트를 **아예 로드하지 않습니다**(미승인 상태 안전).
   - 실제 ID면 `adsbygoogle.js` 를 로드하고, **`.ad-slot__body` 안에만** 광고 단위(`<ins class="adsbygoogle">`)를 삽입합니다.
   - `.ad-slot` 이 **있는 페이지에서만** 광고를 로드합니다. (구현: `scripts/app.js` 의 `App.loadAds`, 호출 분기 `if (document.querySelector(".ad-slot")) App.loadAds()`)

### 광고가 뜨는 위치 (= `.ad-slot` 이 있는 페이지)
- 콘텐츠 페이지 **하단에만**: guide, about, privacy, contact, 그리고 식물 상세 10종.
- **광고 없는 페이지**(의도된 정책): `index.html`, `quiz.html`(도구), `result.html`(결과).
  → 결과·도구 위 광고 금지 원칙을 코드 구조로 보장하고 있습니다.

> ID를 config.js 외 다른 곳에 하드코딩하지 마세요. NEXT_PUBLIC_ 등 빌드 환경변수도 금지(정적사이트).

## 3. 광고 배치 원칙 (시니어 신뢰 보호)

- 광고는 **콘텐츠가 끝난 뒤 하단**에만. 본문·버튼·결과 위에 절대 두지 않습니다.
- 자동재생·소리·전면(모달) 광고 금지.
- "광고" 라벨(`.ad-slot__tag`)을 광고 위에 표시해 콘텐츠와 구분합니다(이미 적용).
- 글자·버튼이 큰 시니어 UI를 광고가 가리지 않도록 합니다.
