# SEO 타깃 키워드 — 우리집 초록친구

시니어(50대 이후) 검색 의도를 우선합니다. 핵심 패턴: `OO 키우는 법`, `OO 물주기`, `OO 햇빛`, `공기정화 식물`, `거실 식물 추천`, `키우기 쉬운 식물`.
키워드 스터핑 금지 — 페이지당 1차 키워드 1개 + 보조 키워드 2~4개를 자연스럽게 본문/메타에 녹입니다.

## 사이트 공통(브랜드/롱테일)
- 우리집 초록친구, 초보 식물 추천, 키우기 쉬운 실내 식물, 처음 키우는 식물, 어르신 식물 키우기

## 루트 페이지

| 페이지 | 1차 키워드 | 보조 키워드 |

## 메모
- 상추/바질은 상세 페이지가 없어(데이터만 존재) 키워드/사이트맵 대상에서 제외.
- 절대 URL 기준(origin)은 `scripts/config.js`의 `SITE_URL` placeholder(`https://example.pages.dev`). 배포 시 sitemap.xml·robots.txt·각 페이지 JSON-LD의 origin을 일괄 치환.
- title은 60자 이내·고유, meta description은 150자 이내·고유 유지(현재 전 페이지 충족).
