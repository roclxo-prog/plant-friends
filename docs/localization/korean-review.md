# 한국어 검수·교정 기록 — 우리집 초록친구

> 시니어가 읽기 자연스럽도록 외래어·번역투·어색한 한자어를 직접 교정한 기록입니다.
> 교정일: 2026-06-06 / 대상: 사용자에게 보이는 텍스트만 (코드 식별자·class·id·data-속성·JSON 키·placeholder는 미변경)

---

## 교정 기준 요약

- 외래어 → 쉬운 우리말 (케어가이드→돌봄 안내, 업데이트→고친 날, 브라우저→인터넷 프로그램, 페이지→화면 등)
- 번역투("~에 대한") → 자연스러운 구어체
- 원예 보편 용어(분갈이·공기정화·반음지·다육 등)와 보편 외래어(쿠팡·이메일·메일·서비스 등)는 유지
- 코드 주석·식별자·JSON-LD 구조 키는 미변경
