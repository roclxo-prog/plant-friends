# 쿠팡 파트너스 링크 채우기 가이드

> 이 문서는 **사용자(운영자)가 직접 채우는** 체크리스트입니다.
> 코드는 건드리지 않아도 됩니다. **링크(URL)만** 복사해 붙여넣으면 됩니다.
>
> 한 줄 전략: 시니어 원예 카테고리는 수수료가 대략 **~3% 수준**으로 높지 않으므로,
> 한 번 팔고 끝나는 식물·화분보다 **흙·비료 같은 소모품(반복구매)** 링크를 꼼꼼히 채우는 것이 누적 수익에 유리합니다.

---

## 1. 쿠팡 파트너스 가입 → 링크 만들기 (처음 한 번만)

1. **가입**: [쿠팡 파트너스](https://partners.coupang.com) 접속 → 쿠팡 계정으로 로그인 → 파트너스 신청.
   - 사이트 주소(우리 서비스 URL)를 등록란에 적습니다.
   - 승인까지 보통 며칠 걸릴 수 있습니다.
2. **내 트래킹 ID 확인**: 승인 후 대시보드 우측 상단/내 정보에서 트래킹 ID(예: `AF1234567`)를 확인합니다.
   - 이 ID는 코드에 **직접 적지 말고**, 개발자가 `scripts/config.js`의 `COUPANG_TRACKING_ID` 에 넣습니다. (3번 참고)
3. **상품 검색**: 파트너스 상단 검색창에 상품명을 검색합니다. (예: "산세베리아", "다육이 흙", "식물 영양제 앰플")
4. **링크 생성**: 원하는 상품을 고르고 **[링크 만들기]** → 짧은 링크(`https://link.coupang.com/...`) 를 **복사**합니다.
   - 이 짧은 링크에는 내 트래킹 ID가 이미 포함되어 있습니다. 그대로 붙여넣으면 됩니다.

> 주의: 가격·재고는 쿠팡에서 수시로 바뀝니다. 가이드/페이지 본문에 **특정 가격·"품절 임박" 같은 단정 표현은 쓰지 마세요.**
> "쿠팡에서 보기" 정도의 중립적 표현만 사용합니다.

---

## 2. 링크를 어디에 붙여넣나? (두 군데)

링크가 들어가는 파일은 **두 곳**이고, 역할이 다릅니다.

| 파일 | 무엇에 쓰이나 | 채우는 값 |
|---|---|---|
| `packages/plants/plants.json` 의 각 식물 `coupang_url` | **추천 결과 화면(result)** 의 "쿠팡에서 보기" 버튼 | 식물 1종당 대표 링크 **1개** (보통 "식물" 본체 링크) |
| `packages/affiliate/coupang-links.json` 의 `products[].url` | 식물별 **추천상품 모음**(식물·화분·흙·영양제 4종) 데이터 | 식물 1종당 **4개** |

- `plants.json` 의 `coupang_url` 이 아직 placeholder(`여기에_쿠팡_링크`)이면, 코드가 자동으로 **쿠팡 검색 결과 페이지로 폴백**합니다. (가짜 링크가 안 나가도록 안전장치가 이미 있음 — `scripts/app.js` 의 `App.coupangUrl`)
- 그래도 **실제 단축링크를 넣어야 수수료가 잡힙니다.** placeholder 검색 폴백은 임시일 뿐입니다.
- `coupang-links.json` 은 식물별 상세 추천 데이터입니다. 향후 식물 상세/가이드에서 활용하기 위한 자리입니다. 4종(식물·화분·흙·영양제)을 모두 채우는 것을 목표로 하세요.

---

## 3. config.js (개발자 작업 — 운영자는 ID만 전달)

- `scripts/config.js` 의 `COUPANG_TRACKING_ID: "여기에_쿠팡_ID"` 를 **실제 트래킹 ID** 로 교체합니다.
- **쿠팡 ID를 다른 파일에 하드코딩하지 마세요.** config.js 한 곳에서만 관리합니다.
- ID 자체는 공개되어도 되는 값입니다(비밀키 아님). 단, 링크 단축본에 이미 ID가 들어있으니 보통은 단축링크만으로 충분합니다.

## 5. 소모품 반복구매 전략 (왜 흙·비료가 중요한가)

- 식물·화분은 **한 번 사면 끝**입니다. 반면 흙·비료는 분갈이·소진 때마다 **다시 삽니다.**
- 같은 방문자가 몇 달 뒤 "분갈이흙"을 다시 찾을 때, 우리 링크가 그 자리에 있으면 **재구매 수수료**가 발생합니다.
- 그래서 48칸 중에서도 **흙·영양제 24칸을 먼저, 정확히** 채우는 것을 권장합니다.
- 상추·바질 같은 **수확 식물**은 수확 후 재파종이 잦아 **씨앗·상토 재구매 수요**가 특히 큽니다.

---

## 6. 정직성 원칙 (반드시 지키기)

- 확인 안 된 가격·재고·할인율을 **단정하지 마세요.** ("최저가", "오늘만", "품절 임박" 금지)
- 시니어 대상 **클릭베이트 금지**. "안 사면 죽어요" 류의 불안 자극 표현 금지.
- 광고·추천 링크는 **콘텐츠 하단**에만. 결과 화면·도구 위에는 절대 두지 않습니다. (사이트 정책)
- 링크에는 `rel="noopener nofollow sponsored"` 가 붙어 있어야 합니다(코드에 이미 적용됨).
