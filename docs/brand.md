# 우리집 초록친구 — 브랜드 가이드

> 50~60대 시니어를 위한 식물 추천 정적사이트.
> 이 문서는 개발자·디자이너가 바로 적용할 수 있도록 확정값(HEX, 폰트, 카피)을 담습니다.

---

## 1. 브랜드명

**우리집 초록친구**

- **의미**: "우리집"은 누구나 돌아오는 편안한 공간을, "초록친구"는 함께 자라며 곁을 지키는 식물을 뜻합니다.
- **유래**: 화분 하나가 집 안의 말동무이자 친구가 되어 준다는 시니어 세대의 정서에서 출발했습니다. 식물을 "키우는 대상"이 아니라 "함께 사는 친구"로 부르는 따뜻한 시선을 담았습니다.
- **브랜드 약속 (한 문장)**: **"처음이라도, 실수해도 괜찮아요. 우리집 초록친구가 당신의 첫 식물을 끝까지 함께합니다."**

## 2. 컬러 팔레트

### 2.1 핵심 색상

| 역할 | 이름 | HEX | RGB | 주 용도 |
|---|---|---|---|---|
| 메인 | 초록 (Green) | `#2E7D32` | 46, 125, 50 | 버튼, 링크, 강조 아이콘, 헤더 포인트 |
| 배경 | 크림 (Cream) | `#F5F0E1` | 245, 240, 225 | 페이지 기본 배경, 카드 배경 |
| 포인트 | 브라운 (Brown) | `#5D4037` | 93, 64, 55 | 화분/흙 모티프, 소제목, 보조 버튼 테두리 |
| 본문 텍스트 | 잉크 (Ink) | `#1B1B1B` | 27, 27, 27 | 본문, 제목 기본 텍스트 |
| 보조(제안) | 연초록 (Soft Green) | `#A5D6A7` | 165, 214, 167 | 배지·태그 배경, 진행바, 비활성 강조 (텍스트 배경 용도 한정) |

> 보조 연초록 `#A5D6A7`은 **배경/장식용**입니다. 이 색 위에는 반드시 어두운 텍스트(`#1B1B1B`)만 올립니다. 흰색/밝은 텍스트는 금지(저대비).

### 2.2 명도 대비 검증 (WCAG AA 기준 4.5:1)

본문은 4.5:1 이상, 큰 텍스트(24px Bold / 18.66px+)는 3:1 이상이면 통과입니다.

| 전경(글자) | 배경 | 대비비 | 본문(4.5:1) | 큰글자(3:1) | 판정 |
|---|---|---|---|---|---|
| `#1B1B1B` 잉크 | `#F5F0E1` 크림 | **15.8:1** | 통과 | 통과 | ✅ 본문 기본 조합 |
| `#1B1B1B` 잉크 | `#FFFFFF` 흰색 | **18.9:1** | 통과 | 통과 | ✅ |
| `#FFFFFF` 흰색 | `#2E7D32` 초록 | **5.1:1** | 통과 | 통과 | ✅ 초록 버튼 + 흰 글자 |
| `#FFFFFF` 흰색 | `#5D4037` 브라운 | **8.9:1** | 통과 | 통과 | ✅ 브라운 버튼 + 흰 글자 |
| `#2E7D32` 초록 | `#F5F0E1` 크림 | **4.6:1** | 통과 | 통과 | ✅ 크림 위 초록 링크 가능 |
| `#5D4037` 브라운 | `#F5F0E1` 크림 | **8.0:1** | 통과 | 통과 | ✅ 크림 위 브라운 소제목 |
| `#1B1B1B` 잉크 | `#A5D6A7` 연초록 | **11.3:1** | 통과 | 통과 | ✅ 배지 위 어두운 글자 |
| `#FFFFFF` 흰색 | `#A5D6A7` 연초록 | **1.7:1** | 실패 | 실패 | ❌ 사용 금지 |
| `#2E7D32` 초록 | `#FFFFFF` 흰색 | **4.1:1** | 실패 | 통과 | ⚠ 본문 텍스트 금지, 큰 제목/아이콘만 |

**개발 적용 규칙**
- 본문 텍스트는 항상 `#1B1B1B` on `#F5F0E1`(또는 흰색).
- 초록 `#2E7D32`을 글자로 쓸 때: 흰 배경에서는 **18px 이하 본문 금지**, 링크/제목/아이콘만. 크림 배경 위에서는 본문 링크로도 사용 가능(4.6:1).
- 버튼: 채움 버튼은 초록/브라운 배경 + 흰 글자. 시인성이 가장 높습니다.

## 3. 폰트(타이포그래피)

### 3.1 폰트 패밀리

- **1순위(우선)**: **Pretendard** — 한글 자형이 크고 또렷해 시니어 가독성에 유리.
- **폴백**: **Noto Sans KR** → 시스템 산세리프.

```css
:root {
  --font-sans: "Pretendard", "Pretendard Variable",
    "Noto Sans KR", -apple-system, BlinkMacSystemFont,
    "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
}
body { font-family: var(--font-sans); }
```

### 3.2 웹폰트 로드 방법 (CDN 예시)

**Pretendard (jsDelivr CDN)** — `<head>`에 추가:

```html
<link rel="stylesheet" as="style" crossorigin
  href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css" />
```

**Noto Sans KR 폴백 (Google Fonts)**:

```html
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700&display=swap" />
```

> `display=swap`으로 폰트 로딩 중에도 텍스트가 즉시 보이게 합니다(시니어 사용자의 빈 화면 대기 최소화).

### 3.3 크기·굵기 적용 원칙 (시니어 가독성)

| 요소 | 크기 | 굵기 | 행간(line-height) |
|---|---|---|---|
| 본문 | **18px 이상** (권장 18~20px) | 400~500 | 1.7 |
| 작은 보조 텍스트 | 16px (최소, 그 이하 금지) | 400 | 1.6 |
| 소제목(h3) | 20~24px | 600 | 1.5 |
| 제목(h2) | **24~28px** | 700 | 1.4 |
| 대제목(h1) | **28~32px** | 700 | 1.3 |
| 버튼 라벨 | 18px 이상 | 600 | — |

**원칙**
- 본문 **18px 미만 금지**. 캡션·각주도 16px 이상.
- 자간은 기본(0) 또는 살짝 넓게(`letter-spacing: 0.01em`). 좁히지 않습니다.
- 한 줄 길이는 한글 기준 35~45자 권장(너무 긴 줄 금지).
- 버튼·터치 영역 최소 높이 48px(손가락이 큰 사용자 배려).

## 4. 톤앤매너

핵심 3요소: **따뜻함 · 존댓말 · 안심**

- 친구처럼 다정하되 예의를 지키는 **존댓말**을 기본으로 합니다.
- 실패를 두려워하지 않도록 **"실수해도 괜찮아요"** 정서를 곳곳에 둡니다.
- 전문용어·영어·약어 대신 **쉬운 우리말**로 풀어 씁니다.

### Do / Don't (시니어 대상 예시 문장)

| 상황 | ✅ Do | ❌ Don't |
|---|---|---|
| 첫 인사 | "어서 오세요. 첫 식물 고르는 걸 천천히 도와드릴게요." | "식물 추천 서비스에 오신 것을 환영합니다." |
| 물주기 안내 | "흙이 말랐을 때 한 컵 정도만 주시면 충분해요." | "관수 주기는 토양 수분 상태에 따라 조절하십시오." |
| 실수 위로 | "잎이 조금 시들어도 괜찮아요. 다시 살릴 수 있어요." | "관리 실패 시 식물이 고사할 수 있습니다." |
| 다음 단계 | "이제 어울리는 화분을 같이 골라볼까요?" | "Next: 화분 옵션을 선택하세요." |
| 어려움 안내 | "이 친구는 손이 조금 가요. 천천히 익숙해지면 돼요." | "고난도 관리 식물입니다. 주의 요망." |

**금지**: 차가운 설명체("~하십시오/~요망"), 영어 위주 표현("Next/Tip/Done"), 한 문장 50자 넘는 긴 안내, 협박성 경고("죽을 수 있습니다").

## 5. 로고 컨셉

### 5.1 워드마크

- 텍스트: **초록친구** (전체 브랜드명은 "우리집 초록친구", 로고 워드마크는 핵심어 "초록친구").
- 폰트: **Pretendard Bold (700)**, 자간 기본.
- 색상: 워드마크 기본은 초록 `#2E7D32`. 단색 적용 시 잉크 `#1B1B1B` 또는 흰색.

### 5.2 심볼 방향성

- **잎 + 화분**의 단순한 결합. 둥근 화분 위로 잎 1~2장이 부드러운 곡선으로 올라오는 형태.
- 곡선·라운드 위주(날카로운 각 지양) → 따뜻하고 안심되는 인상.
- 잎은 초록 `#2E7D32` / 연초록 `#A5D6A7`, 화분은 브라운 `#5D4037`.
- 디테일 최소화: 작은 파비콘에서도 형태가 또렷이 보이도록 면(shape) 중심으로 그립니다.

### 5.3 파비콘 / OG 적용 가이드

**파비콘**
- 심볼(잎+화분)만 사용, 워드마크 제외.
- 배경: 크림 `#F5F0E1` 또는 투명. 16×16에서도 잎-화분 실루엣이 구분되게 단순화.
- 파일: `favicon.svg`(우선) + `favicon-32.png`, `favicon-16.png`, `apple-touch-icon.png`(180×180).

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="icon" href="/favicon-32.png" sizes="32x32" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
```

**OG 이미지 (1200×630)**
- 배경 크림 `#F5F0E1`, 좌측에 심볼, 중앙에 워드마크 "우리집 초록친구"(초록 `#2E7D32`, Pretendard Bold).
- 하단에 약속 한 줄: "실수해도 괜찮아요. 당신의 첫 식물 친구."
- 텍스트는 크게(48px+) — 미리보기 썸네일에서도 읽히게.

```html
<meta property="og:title" content="우리집 초록친구" />
<meta property="og:description" content="50대 이후, 처음 키우는 식물도 실수해도 괜찮아요. 어울리는 초록친구를 천천히 골라드려요." />
<meta property="og:image" content="/og-image.png" />
<meta property="og:type" content="website" />
```

## 6. 보이스 예시 — 나쁜 예 vs 좋은 예

같은 메시지를 비교합니다. 좋은 예의 공통점: **짧다 · 존댓말 · 따뜻하다**.

| 메시지 의도 | ❌ 나쁜 예 (차갑/영문/긴 문장) | ✅ 좋은 예 (따뜻/짧음/존댓말) |
|---|---|---|
| 추천 시작 | "사용자 정보를 기반으로 최적의 식물을 매칭하기 위해 몇 가지 항목을 입력해 주시기 바랍니다." | "몇 가지만 여쭤보고, 잘 맞는 친구를 찾아드릴게요." |
| 결과 안내 | "Result: 귀하에게 추천되는 식물은 스킨답서스입니다." | "당신께 딱 맞는 친구는 스킨답서스예요." |
| 관리 팁 | "Tip: 직사광선을 피하고 적정 습도를 유지하며 통풍이 잘 되는 환경에서 관리하시기 바랍니다." | "햇빛 강한 곳은 피해 주세요. 바람 잘 통하면 더 좋아요." |
| 실수 위로 | "Warning: 과습으로 인해 뿌리가 손상되었을 가능성이 있습니다." | "물이 좀 많았나 봐요. 며칠 말려주면 다시 괜찮아져요." |
| 완료 | "Done. 설정이 정상적으로 저장되었습니다." | "다 됐어요. 잘 저장해 두었어요." |
| 오류 | "Error: 요청을 처리할 수 없습니다. 다시 시도하십시오." | "잠깐 문제가 있었어요. 한 번만 다시 눌러 주세요." |
