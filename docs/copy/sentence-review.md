# 문장 재검수 — 시니어 친화 짧은 문장(15자 이내 지향)

> 검수자: copy-writer · 날짜: 2026-06-06
> 기준: 버튼·라벨·제목·안내 문구는 **15자 이내 지향**(불가피하면 두 줄). 본문 설명 문단은 예외(자연스러움 우선)이되 한 문장은 짧게.
> 존댓말 유지 · 외래어/어려운 한자어 금지 · 영문 CTA 금지 · 시니어 후킹("안 죽이는·쉬워요·1분").
> 글자수는 **이모지 제외, 공백 포함** 화면 표시 기준. ★ = 15자 초과 UI 핵심 문구(우선 수정 대상).

## D. 발견된 불일치(카피 일관성 — 참고)

- **copy-deck vs result.js 빈결과 본문 불일치**: copy-deck.md(119행)는 "답을 조금 바꿔서 다시 해 볼까요?"이나, 실제 result.js(102행)는 "질문에 답하면 우리집에 맞는 식물을 찾아 드려요." → 둘 중 하나로 통일 권장(둘 다 15자 초과, C 표의 단축안 권장).
- **결과 부제 톤 불일치**: 화면 제목/이유 템플릿은 "우리집"·"친구" 톤인데 부제만 "어르신께"로 직접 호칭 → "우리집" 톤으로 통일 권장(C 표).
- **버튼 표기 일관**: 모든 CTA가 한글+이모지로 영문 CTA 없음 → 기준 충족(유지).
