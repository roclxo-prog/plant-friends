# 문구 모음 — 우리집 초록친구

> 페이지별 화면 문구 모음입니다. 모두 존댓말, 짧은 문장, 쉬운 우리말로 적었습니다.
> 영문 버튼 글자는 노출하지 않습니다. 이모지와 한글을 함께 씁니다.

## 1. 시작 (index)

### 첫 화면

- **제목**: 우리집에 맞는 식물, 1분이면 찾아요
- **부제**: 질문 3개만 답하면 돼요.
- **부제 보조**: 가입도, 사진도 필요 없어요.

### 추천 버튼

- **주 버튼**: 🌱 식물 추천받기

### 안심 문구

- 처음이라도 괜찮아요.
- 실수해도 다시 키울 수 있어요.
- 큰 글씨로 쉽게 알려 드려요.

### 보조 안내

- 키우기 쉬운 식물만 골랐어요.
- 한국에서 쉽게 살 수 있어요.

## 2. 질문 (quiz)

### 진행 안내

- 필수 단계 표시: 3개 중 1번째 (2번째 / 3번째)
- 정밀화 단계 표시: 4 / 7 (5/7 · 6/7 · 7/7) · 모르시면 건너뛰셔도 돼요.
- 격려 문구: 천천히 고르셔도 돼요.

### Q1 — 빛 (light)

- **질문**: 식물 둘 곳에 햇빛이 잘 드나요?
- **보기**:
  - ☀️ 햇빛이 잘 들어요
  - ⛅ 조금 들어요
  - 🌙 빛이 약해요

### Q2 — 물 (water)

- **질문**: 물은 자주 챙겨 주실 수 있나요?
- **보기**:
  - 💧 자주 줄 수 있어요
  - 🌿 가끔 줄 수 있어요
  - 🍃 자주 깜빡해요

### Q3 — 목적 (purpose)

- **질문**: 어떤 식물을 찾으세요?
- **보기**:
  - 🌳 공기 맑게 하는 식물
  - 🌸 꽃이 예쁜 식물
  - 🪴 작고 귀여운 식물
  - 🥬 먹을 수 있는 식물

### 분기 화면 (필수 3문항 완료 후)

- **제목**: 필수 질문 3개를 마쳤어요!
- **안내**: 이대로 추천받으셔도 되고, 몇 가지만 더 알려 주시면 더 잘 맞는 식물을 찾아 드려요.
- **버튼**:
  - ✅ 이대로 추천받기
  - 🔎 더 정확히 추천받기 (4문항)

### Q4 — 장소 (place, 선택)

- **질문**: 어디에 두실 건가요?
- **보기**:
  - 🛋️ 거실
  - 🪟 베란다·창가
  - 🚿 욕실·습한 곳
  - 🖥️ 책상·사무실
  - 🤷 잘 모르겠어요 (건너뛰기)

### Q5 — 반려동물 (pet, 선택)

- **질문**: 강아지나 고양이를 키우세요?
- **보기**:
  - 🐶 강아지·고양이 있어요
  - 🙆 없어요
  - 🤷 잘 모르겠어요 (건너뛰기)
- 안내: "있어요"를 고르시면 반려동물에게 안전한 식물만 추천해 드려요.

### Q6 — 크기 (size, 선택)

- **질문**: 어느 정도 크기가 좋으세요?
- **보기**:
  - 🌱 작은 탁상용
  - 🪴 중간 크기
  - 🌳 큰 거실용
  - 🤷 잘 모르겠어요 (건너뛰기)

### Q7 — 보는 재미 (interest, 선택)

- **질문**: 무엇을 보는 재미가 좋으세요?
- **보기**:
  - 🌸 꽃
  - 🍃 잎·무늬
  - 🍅 열매·단풍
  - 🤷 상관없어요 (건너뛰기)

## 3. 결과 (result)

### 머리말

- **제목**: 우리집에 딱 맞는 친구예요
- **부제**: 어르신께 잘 어울리는 식물 3가지예요.

### "왜 맞는지" 한 줄 이유 템플릿

> 빛·물·목적 조합으로 한 줄 이유를 만듭니다. 모두 15자 안팎, 존댓말.

- 빛 강함 + 물 자주: 햇빛 좋고 물 좋아하는 친구예요.
- 빛 강함 + 물 가끔: 햇빛 좋아하고 손이 덜 가요.
- 빛 약함 + 물 가끔: 그늘에서도 잘 자라요.
- 빛 약함 + 물 깜빡: 빛 적고 물 잊어도 괜찮아요.
- 목적 공기: 공기 맑게 해 줘요.
- 목적 꽃: 예쁜 꽃을 볼 수 있어요.
- 목적 작은 식물: 작고 키우기 쉬워요.
- 목적 먹는 식물: 길러서 드실 수 있어요.
- 처음 + 쉬움: 처음이라도 잘 키워요.
- 반려동물 안전: 반려동물에게 안전한 식물이에요.
- 장소 거실: 거실에 두기 좋아요.
- 장소 창가: 베란다·창가에 잘 어울려요.
- 장소 욕실: 습한 욕실에서도 잘 자라요.
- 장소 책상: 작아서 책상에 딱 맞아요.
- 크기 작음: 작아서 어디에나 두기 좋아요.
- 크기 큼: 크게 자라 거실을 채워 줘요.
- 보는 재미 꽃: 예쁜 꽃이 피어요.
- 보는 재미 잎: 잎과 무늬가 멋져요.
- 보는 재미 열매: 열매·단풍을 볼 수 있어요.

### 버튼 글자

- 🔎 자세히 보기
- 🛒 쿠팡에서 보기
- 💬 카톡으로 공유

- 어느 친구든 키우기 쉬워요.
- 천천히 골라 보세요.
