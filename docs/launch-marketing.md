# 출시 마케팅 전략 — 우리집 초록친구

> 대상: 50~60대 시니어. 원칙: **시니어 신뢰 우선**. 도배·스팸·클릭베이트·허위효능 금지, 존댓말.
> 근거 문서: `docs/brand.md`(톤), `우리집초록친구_기획안.md` 12장(홍보 전략), `docs/copy/copy-deck.md`, `docs/monetization-strategy.md`.
> 보조 산출물: `docs/social/youtube-script.md`(60초 대본), `docs/social/share-templates.md`(카톡·밴드 글).

## 1. 채널 전략 개요 — 50+ 채널 공식

핵심 원칙: **50~60대가 실제 머무는 곳에 간다.** 인스타그램·스레드는 50+ 도달이 약하고 피드형 소비라 정보 탐색·전환에 비효율입니다. 그래서 비주력으로 둡니다.

대신 시니어가 **정보를 찾고(검색·유튜브), 모이고(밴드·카페), 나누는(카톡)** 세 흐름에 집중합니다.

| 우선 | 채널 | 역할 | 시니어 적합 이유 |
|---|---|---|---|
| **1순위** | 네이버 밴드 / 카페 | 신뢰 기반 커뮤니티 유입 | 50+ 취미·동네 활동이 밴드/카페 중심 |
| **2순위** | 유튜브(60초 쇼츠) | 정보검색 유입 | 시니어는 유튜브를 '검색'으로 사용 |
| **2순위** | 검색(구글·네이버) | 롱테일 누적 유입 | "○○ 키우는 법" 검색 의도 강함 |
| **상시** | 카카오톡 공유 루프 | 입소문 확산 | 시니어 공유 = 카톡 |
| 옵션 | 노인복지관·원예치료 제휴 | 오프라인 신뢰 | 대면 신뢰가 디지털 장벽을 넘음 |
| 비주력 | 인스타·스레드 | 보조 노출만 | 50+ 도달 약함 → 자원 최소 |

> 전환 동선은 항상 동일: **밴드/유튜브/카톡 → 질문 3개(1분) → 추천 결과 → 케어가이드/쿠팡(하단)**. 결과·도구 화면 위에는 광고·배너를 두지 않습니다(`docs/monetization-strategy.md` 3장).

## 2. 네이버 밴드 / 카페 (1순위)

가장 중요한 채널입니다. 다만 **도배하면 즉시 차단·강퇴**되어 역효과입니다. 원칙은 "먼저 도움이 되고, 도구는 자연스럽게".

### 2-1. 대상 커뮤니티 예시
> 명칭은 예시입니다. 가입 전 규모·활동성·홍보 규정을 반드시 확인하세요.

- **네이버 카페**: 식물 키우기/반려식물 커뮤니티, 다육이 동호회, 텃밭·주말농장 카페, 베란다 정원 카페.
- **네이버 밴드**: 동네·아파트 화초 나눔 밴드, 실버 취미·원예 밴드, 텃밭 가꾸기 밴드.
- **검색 키워드**: "식물 키우기 카페", "다육이 카페", "텃밭 밴드", "베란다 정원".

### 2-2. 도배 금지 원칙 (절대)
1. **먼저 활동, 나중에 소개.** 가입 직후 글쓰기 금지 — 며칠간 댓글·좋아요·내 식물 사진으로 신뢰부터 쌓습니다.
2. **같은 글 복붙 금지.** 여러 카페에 동시 도배 = 스팸 신고 사유. 글마다 내 경험을 넣어 다르게 씁니다.
3. **링크는 한 글에 1개 이하, 본문 상단 지양.** 링크는 요청이 있을 때 댓글로.
4. **카페·밴드별 광고 규정 우선 확인.** 위반 시 강퇴·신고.
5. **효능 단정·과장 금지**("미세먼지 다 없앤다" 류 금지).

### 2-3. 자연스러운 활동 글 예시 (시니어 톤, 존댓말)
> 전체 버전·댓글형은 `docs/social/share-templates.md` 2장 참조. 핵심 3개 요약:

**예시 ① 경험 나눔 (가장 자연스러움)**
```
제목: 처음 키운 산세베리아, 반년째 잘 살아요 :)

식물은 처음이라 늘 죽이기만 했는데, 물을 자주 안 줘도 되는
산세베리아는 반년째 잘 자라네요. 빛 약한 거실에서도 괜찮았어요.
처음이신 분들은 물 자주 안 줘도 되는 걸로 시작하시면 마음이 편해요.
우리집에 뭐가 맞을지 모르겠으면 질문 몇 개 답하면 골라주는 곳도 있더라고요.
필요하신 분 댓글 주세요.
```

**예시 ② 질문 글에 다는 답변(댓글)**
```
저도 같은 고민이었어요. 빛 약한 방이면 산세베리아나 스킨답서스가 잘 맞아요.
물도 자주 안 줘도 돼요. 질문 3개 답하면 맞는 식물 골라주는 곳에서 저는
스킨답서스가 나왔는데 잘 키우고 있어요. 가입도 사진도 필요 없어요 :)
```

**예시 ③ 케어 팁 나눔 (정보 제공형)**
```
제목: 식물 물주기, 저는 이렇게 하니 안 죽더라고요

정해진 날짜에 주는 것보다, 흙을 손가락으로 눌러보고 말랐을 때
한 컵 정도만 주니까 훨씬 잘 자라요. 잎이 시들어도 며칠 말려주면
다시 괜찮아지더라고요. 처음이신 분들 너무 어렵게 생각 안 하셔도 돼요.
```

### 2-4. 광고성 차단 회피 = 신뢰 유지
- 주 2~3회만, 도움 답변 위주. "글 쓰러 들어가는" 느낌이 아니라 "동호회 활동하다 가끔 소개".
- 프로필·닉네임을 일관되게(브랜드 계정 티가 너무 나면 경계함).
- 한 카페에서 신뢰가 쌓이면 그곳에서만 자연스럽게 확장.

## 3. 유튜브 60초 쇼츠 (정보 유입)

시니어는 유튜브를 '검색 엔진'처럼 씁니다. "초보도 안 죽이는 식물 추천" 같은 정보형 쇼츠로 유입합니다.

> 전체 장면별 대본·설명란·제작법은 `docs/social/youtube-script.md` 참조. 핵심만 요약:

- **후킹 3초**: "식물, 사다가 금방 시들어서 속상하셨지요? 처음이라도 안 죽이는 식물부터 알려드릴게요."
- **중간(가치)**: 산세베리아·스킨답서스·금전수 3종 → 공통점("물 자주 안 줘도 됨, 빛 약해도 됨")으로 "왜 초보에게 맞는지" 설명.
- **CTA**: "아래 설명란 링크에서 질문 3개만 답하면 1분 만에 우리집 맞는 식물 찾아드려요. 가입도 사진도 필요 없어요."
- **마무리**: "실수해도 괜찮아요. 천천히 같이 키워봐요."

**설명란**: 사이트 링크 + `guide.html` 링크 + 타임스탬프 + 검색 의도 해시태그 8~12개(`#키우기쉬운식물 #실내식물추천 #초보식물 #공기정화식물` 등, `docs/seo-keywords.md` 연동). 쿠팡 링크는 설명 상단 금지.

**촬영 없이 만드는 대안(슬라이드 + TTS)**: 얼굴 노출·촬영 없이 제작 가능.
1. 라이선스 안전한 식물 사진(`docs/asset-licenses.md`) — 사이트 사진 재사용 가능.
2. 세로 9:16 슬라이드, 자막 48px+ 큰 글씨(크림 배경+잉크 글자).
3. 한국어 TTS 내레이션(말 속도 느리게).
4. CapCut/캔바로 슬라이드+음성+전체 자막 합성. 1편 ≈ 30~60분.

## 4. 카카오톡 공유 루프

시니어의 공유는 곧 카톡입니다. 결과 페이지에 이미 카톡 공유 버튼이 있습니다(`scripts/result.js`, `scripts/app.js` — `navigator.share` 우선, 폴백은 링크 복사).

### 4-1. 공유 메시지 템플릿 (요약, 전체는 `docs/social/share-templates.md`)
**자녀에게 / 자녀가 부모님께**
```
엄마, 이거 질문 세 개만 누르면 우리집에 맞는 식물 골라줘요.
가입도 사진도 필요 없어요. 한번 해보세요 🌱 [링크]
```
**친구·또래에게**
```
○○님, 키우기 쉬운 식물 찾으셨지요? 질문 3개 답하니 우리집에 맞는 친구
알려주네요. 물 자주 안 줘도 되는 걸로요 :) [링크]
```
**결과 자랑형**
```
저는 '스킨답서스'가 나왔어요 🌿 빛 약한 우리집에도 맞는대요.
○○님은 뭐 나오는지 해보세요. [결과 링크]
```

### 4-2. OG 미리보기 활용
- 카톡에 링크를 붙이면 미리보기 카드(제목·설명·이미지)가 자동으로 뜹니다 → 클릭률 상승.
- 카드 내용은 각 페이지 `og:title`/`og:description`, 이미지는 `/public/og-image.png`(1200×630, 크림 배경 + "실수해도 괜찮아요. 당신의 첫 식물 친구").
- **배포 시 필수**: `scripts/config.js`의 `KAKAO_JS_KEY`와 절대 URL을 실제값으로 교체 후, **카카오 공유 디버거**로 미리보기 정상 노출 1회 확인.
- 메시지는 **한두 줄 + 링크**가 가장 잘 열립니다(길게 쓰지 않기).

## 5. 검색 유입 (SEO)

롱테일 검색이 가장 안정적인 누적 유입원입니다.

- **케어가이드 페이지**: `guide.html` + 식물 상세 10종(`plants/*.html`)이 "○○ 키우는 법 / 물주기 / 햇빛" 검색 의도를 흡수합니다. 페이지당 1차 키워드 1개 + 보조 2~4개(`docs/seo-keywords.md`), 키워드 스터핑 금지.
- **색인 등록**: 구글 Search Console + 네이버 서치어드바이저에 사이트맵(`sitemap.xml`) 제출. **등록 절차 상세는 `docs/seo-registration.md` 참조**(배포 도메인으로 `SITE_URL` 일괄 치환, robots.txt·JSON-LD origin 교체 포함).
- 유튜브 영상·밴드 글의 키워드를 사이트 키워드와 일치시켜 검색·추천 알고리즘에 시그널을 모읍니다.

## 6. (옵션) 노인복지관 · 원예치료 제휴

오프라인 대면 신뢰는 디지털 장벽을 넘는 가장 강력한 채널입니다.

- **대상**: 지역 노인복지관, 주민센터 원예·취미 강좌, 원예치료 프로그램, 평생학습관.
- **접근법**: 영업이 아니라 **무료 도움 자료** 제공으로 시작. "큰 글씨 식물 키우기 안내문"·"우리집 맞는 식물 찾기(1분)" 활동지를 인쇄물/QR로 제공.
- **신뢰 포인트**: 가입·결제·개인정보 수집이 없다는 점(시니어·기관 모두 안심), 존댓말·큰 글씨 UX.
- 강좌 참가자가 집에서 카톡으로 가족과 공유 → 4번 공유 루프로 연결.

## 7. 콘텐츠 캘린더 (4주)

> 출시 후 4주. 무리한 도배 대신 **주 단위 적정량**으로 신뢰를 쌓습니다.

| 주차 | 검색/SEO | 유튜브(쇼츠) | 밴드·카페 | 카톡/기타 |
|---|---|---|---|---|
| **1주차 (기반)** | Search Console·네이버 등록, 사이트맵 제출(`seo-registration.md`), OG/카카오 디버거 확인 | 1편: "처음 키워도 안 죽는 식물 3가지" | 카페·밴드 2~3곳 가입, **활동만**(댓글·좋아요·인사) | 가족·지인에게 결과 공유 테스트 |
| **2주차 (진입)** | guide·식물 상세 색인 확인, 미색인 페이지 재요청 | 2편: "물 자주 깜빡해도 사는 식물" | 질문 글에 **도움 답변** 시작(링크는 요청 시 댓글) | 공유 메시지 템플릿으로 또래 전파 |
| **3주차 (확산)** | 검색어 유입 점검, 부족 키워드 보강 | 3편: "빛 안 드는 방 식물" | 경험 나눔 글 1~2개(예시 ①③), 신뢰 쌓인 카페 집중 | (옵션) 복지관·강좌 1곳 자료 제안 |
| **4주차 (정착)** | 상위 유입 페이지 분석, 내부링크 보강 | 4편: "선물하기 좋은 화분" 또는 식물별 케어 | 케어 팁 나눔, 댓글 응대 지속 | 성과 지표 1차 집계·다음 달 계획 |

> 발행 리듬: 유튜브 **주 1편**, 밴드/카페 **주 2~3회 도움 활동**, 카톡은 상시. 같은 글 복붙 금지.

## 8. 성과 지표 (KPI)

| 지표 | 정의 | 측정 방법 | 초기 목표(가이드) |
|---|---|---|---|
| **유입(세션)** | 사이트 방문 수 | GA/Search Console, 채널별 UTM | 채널별 추이 우상향 |
| **추천 완료율** | 질문 시작 → 결과 도달 비율 | quiz→result 이벤트 | 60%+ |
| **쿠팡 클릭** | 결과·식물 페이지 쿠팡 링크 클릭 | 쿠팡 파트너스 리포트 | 방문 대비 클릭률 추적 |
| **카톡 공유 수** | 공유 버튼 클릭/공유 완료 | 공유 이벤트 카운트 | 공유 → 신규 유입 전환 확인 |
| (보조) 검색 노출/클릭 | 색인 키워드 노출·CTR | Search Console / 네이버 | 롱테일 페이지 수 증가 |
| (보조) 영상 조회·CTR | 쇼츠 조회·설명란 링크 클릭 | 유튜브 스튜디오 | 후킹 3초 A/B 개선 |

> 모든 지표는 **신뢰 자산** 관점에서 봅니다. 단기 클릭보다 재방문·재공유·재구매(소모품)가 장기 수익을 키웁니다(`docs/monetization-strategy.md`).

## 9. 제약 요약 (전 채널 공통)
- 도배·스팸·클릭베이트·허위효능 **금지**.
