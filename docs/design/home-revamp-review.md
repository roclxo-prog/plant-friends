## 1. 점검 결과 (항목별)

### 1) 오늘의 추천 3종 카드
- 구조: 사진(3:2) → 이름(24px/700) → 특징 → 추천대상 알약(`.badge`) → 버튼 2개(자세히 보기·쿠팡). 균형 양호.
- 정렬: `.featured-grid` 모바일 1열 / 768px+ 3열 — 요구대로 동작. ✅
- 버튼: `.btn` min-height 56px(>48). 카드 높이 달라도 `.featured-card__actions { margin-top:auto }` 로 버튼 줄 바닥 정렬됨. ✅
- 사진 위 글씨: 없음(이름·특징은 흰 바디 영역). ✅
- **발견한 문제**: `featured-card__merit` 가 `plant.merit` 전문을 그대로 출력 → 식물마다 특징 문장 길이가 달라 카드 본문 높이가 들쭉날쭉. (개선 적용)

### 2) 랭킹 4구좌
- 순위 배지 `.rank-card__num`: 36px 원형, green-600 + 흰 글자(5.1:1) + 흰 테두리. 가독성 양호. ✅
- 가로 스크롤: `scroll-snap-type: x mandatory` + 카드 200px(좁은 화면 168px). 컨테이너 폭 대비 2장+α 노출로 다음 카드 힌트는 있으나, 첫 카드가 모서리에 붙어 잘려 보이고 마지막 카드 그림자가 잘림. (개선 적용)
- "쿠팡에서 보기 🛒" 버튼: `.rank-card__shop` 이 `.btn`(56px) 상속 → 48px+ 충족. ✅
- 제목 위계: 섹션 h2 → 블록 h3. 정상. ✅

### 3) 상단 메뉴 4항목(추천받기·돌봄 안내·읽을거리·소개)
- **발견한 문제 A (넘침)**: 18px 유지 시 로고+메뉴 4개가 한 줄에 들어가지 않아(추정 합산 폭 약 475px > 320px), `flex-wrap:wrap` 으로 어색하게 줄바꿈됨. 브랜드 규칙 "320px 무넘침·줄바꿈 없음" 위반. (개선 적용)
- **발견한 문제 B (현재 페이지 강조 미작동)**: 하위 페이지 HTML에는 `aria-current="page"` 가 이미 있으나(`about/quiz/guide/articles.html`), `styles.css` 에 `.site-nav a[aria-current="page"]` 스타일이 **전혀 없어 시각적 강조가 렌더되지 않음**. (개선 적용)

### 4) 제휴 표시
- `.affiliate-note`: 18px(하한 유지), 흰 카드 + 브라운 왼쪽 테두리 6px로 본문과 구분, 신뢰감 있는 톤. ✅ (요구 18px+ 충족)

### 5) 전체 톤 일관
- 유리효과: 헤더(sticky, backdrop-blur)·하단 네비에만 적용, 카드는 모두 불투명 흰색. 규칙 준수. ✅
- 카드 모서리 24px(`--radius-card`), 초록 포인트, 베이지 배경 일관. ✅
- 흐름: 히어로 → 오늘의 추천 → 랭킹 → 안심 → 이용방법 → 보조안심. 자연스러움. ✅

### 6) 반응형
- 헤드리스 브라우저(playwright/puppeteer) 미설치 → 정적 분석으로 320/375/768/1280 폭 계산 검증.

## 2. 적용한 개선 (직접 수정)

모두 토큰 기반·안전 범위. 수정 파일: `styles/styles.css`.

1. **현재 페이지 메뉴 강조 신설** — `.site-nav a[aria-current="page"]`: green-700 색 + 밑줄 3px + offset 6px. 색 단독 의존이 아닌 색+굵기(700 기존)+밑줄 다중 표기로 접근성 충족. (그동안 보이지 않던 강조를 실제로 렌더)
2. **상단 메뉴 320–414px 무넘침** — `@media (max-width:414px)`: 헤더를 2행(로고 윗줄 / 메뉴 풀폭 아랫줄)으로 전환, 메뉴는 `justify-content:space-between` + `white-space:nowrap` 로 4개를 한 줄 균등 배치. `@media (max-width:360px)` 에서 헤더·항목 패딩 추가 축소(글자 18px 유지). 320px 계산상 무넘침.
3. **랭킹 가로 스크롤 힌트·스냅 개선** — `.rank-row`: `scroll-padding-left:4px`(첫 카드 잘림 방지) + `padding-right: var(--space-4)`(마지막 카드 그림자 보존 + 다음 카드 살짝 보이는 peek 힌트).
4. **추천 카드 높이 균일화** — `.featured-card__merit`: `-webkit-line-clamp:3` 로 특징을 3줄 고정·줄임표 처리(18px 유지). 카드 본문 높이 들쭉날쭉 해소, 자세한 설명은 "자세히 보기"로 연결.
5. **(검증/정리)** 메뉴 18px 하한·버튼 48px+·배지 대비·사진 위 글씨 금지·유리 헤더/네비 한정 원칙이 개편 섹션 전반에서 유지됨을 확인하고, 위 변경이 모든 절대 규칙을 깨지 않도록 적용.
