## 2. 항목별 점검

### 2-1. 새 진행바 (n/7 + 막대 + 점7) — 19/20
- "n / 7" 우측 정렬, 현재 숫자만 green-600 강조 → 명확. 격려문(green-700) 좌측. 줄바꿈 금지(`white-space:nowrap`) 정상.
- 막대 14px 두께·연초록 트랙·초록 채움 → 시니어 가시성 양호. 점7은 보조로 `aria-hidden`, progressbar는 막대에 부여(중복 readout 방지) → 접근성 정석.
- **개선 적용**: ①막대 채움 1/7(14%)에서 둥근 끝이 뭉개지지 않게 `min-width:14px`. ②점 행이 현재 점(20px) 확대 시 높이가 출렁이던 문제를 `align-items:center` + `min-height:20px`로 고정. ③현재 점에 `box-shadow` 연초록 후광 추가로 "지금 여기" 인지 강화.

### 2-2. 7문항 선택 화면 리듬 — 19/20
- choice-card 96px·이모지 40px·라벨 20px Bold·좌측 정렬 → 시니어 친화.
- 격려문은 진행바 위(굵게) + 보조 힌트는 질문 위(`aria-live`) 2단 배치로 위치 적절.
- **개선 적용**: ④카드 간격을 12px→16px(`--space-2`)로 넓혀 96px 카드가 더 또렷이 분리. ⑤이모지 칸 폭 통일(`width:44px;text-align:center`)로 라벨 시작선이 카드마다 정렬(이모지 폭 편차로 들쭉날쭉하던 것 해소).

### 2-3. 브랜드 일관성 — 19/20
- 컬러(#2E7D32 등)·카드 24px·버튼 16px·`--shadow-card/float`가 토큰 단일 출처로 전 페이지 일관.
- 헤더/네비 유리 톤, 로고 green-700, 페이지 배경 베이지 통일.
- 미세 메모(미수정, 의도된 토큰 정제로 판단): tokens.css의 `--ink #1A1A1A`·`--green-100 #E8F3E9`는 brand.md의 `#1B1B1B`·`#A5D6A7`와 다르나, 대비가 오히려 더 안전(연초록 알약 위 대비 11.3→15.3:1)하고 토큰이 단일 출처이므로 그대로 유지 권장. 필요 시 brand.md 부록 수치를 토큰값으로 동기화하면 문서 일관성↑.

### 2-4. 결과/상세 카드 — 19/20
- 결과 카드: 사진(3:2)–이름(24px)–이유(18px)–팩트 알약(빛/물)–버튼3 수직 흐름이 깔끔. 알약은 연초록 배경+잉크(대비 15.3:1). 버튼 위계(초록 자세히 / 브라운 쿠팡 / 흰 공유) 명확.
- 상세(info-card): 아이콘+제목+값 그리드, 경고 카드 좌측 6px 빨강 바 → 색 외 정보 병기 양호.
- 추가 손볼 곳 없음(현 상태로 완성도 충분).

### 2-5. Hard Rules 유지 — 충족
- 위 1절 실측대로 7개 규칙 전부 통과.

## 3. 적용한 개선 목록 (styles.css, 토큰 기반·안전 범위)

1. **진행 막대 채움 min-width 14px** — 1/7 단계에서도 둥근 끝(pill) 가시성 유지.
2. **점 행 높이 고정** — `.progress__dots`에 `align-items:center` + `min-height:20px`로 현재 점 확대 시 수직 점프 제거.
3. **현재 점 후광** — `.progress__dot.is-current`에 `box-shadow:0 0 0 3px var(--green-100)`로 현재 단계 강조 강화(색만 의존 아님: 크기+테두리+후광).
4. **선택 카드 간격 16px** — `.choice-group` gap `--gap-min`(12px)→`--space-2`(16px). 96px 카드 분리 인지 개선.
5. **이모지 칸 폭 통일** — `.choice-card__emoji`에 `width:44px;text-align:center`로 라벨 시작선 정렬.

> 모두 토큰/기존 규격 내 소폭 조정. 마크업·JS 변경 없음. 레이아웃 폭·대비·유리 위치에 영향 없음(재검증으로 확인).
