# ads.txt 채우는 법 (우리집 초록친구)

> 대상 파일: `C:\projects\plant-friends\ads.txt`
> 배포 후 주소: `https://plant-friends.pages.dev/ads.txt`

---

## ads.txt 가 뭔가요

`ads.txt`(Authorized Digital Sellers)는 **"이 사이트의 광고 지면을 누가 정식으로 팔 수 있는가"**를 선언하는 공개 파일입니다.
광고 사기(다른 사람이 내 사이트인 척 광고를 파는 일)를 막아 주고, 애드센스 수익을 보호합니다.

애드센스는 승인 후 이 파일이 없거나 비어 있으면 관리 화면에
**"수익 손실 위험이 있습니다 — ads.txt 파일 문제를 해결하세요"** 라는 경고를 띄웁니다.
승인 자체에 필수는 아니지만, **승인 직후 바로 채워 두는 것이 좋습니다.**

---

## 채우는 순서 (애드센스 승인 후)

1. 애드센스 가입·승인이 끝나면, 게시자 ID를 확인합니다.
   - 애드센스 → 계정 → 계정 정보 → **게시자 ID**: `pub-XXXXXXXXXXXXXXXX` 형태.
   - (광고 코드에 보이는 `ca-pub-1234...` 에서 앞의 `ca-` 를 뗀 값이 `pub-1234...` 입니다.)

2. `ads.txt` 파일을 열어, 맨 아래 한 줄을 본인 ID로 바꾸고 `#` 를 떼어 활성화합니다.

   **바꾸기 전 (현재, 비활성):**
   ```
   # google.com, pub-여기에_숫자, DIRECT, f08c47fec0942fa0
   ```

   **바꾼 뒤 (활성, 예시):**
   ```
   google.com, pub-1234567890123456, DIRECT, f08c47fec0942fa0
   ```

3. 줄 형식 그대로 두세요(쉼표·띄어쓰기 포함). 한 사이트에 한 줄이면 충분합니다.
   - `google.com` : 광고를 파는 시스템(구글). 고정.
   - `pub-...` : **본인 게시자 ID만** 교체.
   - `DIRECT` : 본인이 직접 판매. 고정.
   - `f08c47fec0942fa0` : 구글의 인증기관 ID(TAG ID). 모든 게시자가 동일. 고정.

4. 저장 후 **다시 배포**합니다(Cloudflare Pages에 push/업로드).

5. 브라우저에서 `https://plant-friends.pages.dev/ads.txt` 로 접속해
   바뀐 한 줄이 그대로 보이는지 확인합니다.

---

## 주의

- pub 번호를 받기 **전에는 줄을 활성화하지 마세요.** `pub-여기에_숫자` 같은 placeholder를
  활성화하면 애드센스가 "유효하지 않은 ads.txt"로 경고합니다. 그래서 현재는 주석(`#`)으로 막아 두었습니다.
- 반영까지 보통 하루 이틀 걸릴 수 있습니다. 경고가 바로 사라지지 않아도 정상입니다.
- 파일은 반드시 **사이트 루트**(`/ads.txt`)에 있어야 합니다. 하위 폴더에 두면 인식되지 않습니다.
