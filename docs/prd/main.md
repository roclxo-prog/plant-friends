# 우리집 초록친구 — 제품 요구사항 정의서(PRD)

50~60대 시니어 사용자를 위한 맞춤 식물 추천 정적 사이트입니다. 어려운 기술이나 가입 절차 없이, 큰 글씨와 큰 버튼으로 누구나 쉽게 우리 집에 어울리는 식물을 찾도록 돕습니다.

## 1. 제품 개요

- **대상 사용자**: 식물 키우기에 관심 있는 50~60대 시니어
- **핵심 가치**: 질문 3개에 답하면 우리 집에 잘 맞는 식물 3종을 추천받고, 큰 글씨 돌보기 안내와 함께 바로 구매까지 이어집니다.
- **기술 형태**: HTML/CSS/순수 자바스크립트로 만든 정적 사이트, `plants.json` 한 개를 데이터로 사용, 클라우드플레어 페이지스 배포, 별도 서버 없음
- **인증**: 가입·로그인 없음
- **수익 구조**: 쿠팡 파트너스(주 수익) + 구글 애드센스(보조 수익)

---

## 2. 사용자 이야기(User Story)

각 이야기에는 검증할 수 있는 합격 기준(Acceptance Criteria)을 함께 적었습니다.

### 이야기 1 — 시작 화면에서 부담 없이 시작하기

시니어 사용자로서, 무엇을 하는 곳인지 한눈에 알고 쉽게 시작하기 위해, 큰 글씨 안내와 큰 시작 버튼이 있는 시작 화면을 원합니다.

**합격 기준**

- [ ] 시작 화면에 서비스 한 줄 설명("질문 3개로 우리 집 식물 찾기")이 본문 18px 이상으로 보입니다.
- [ ] "시작하기" 버튼이 화면에서 가장 크고(높이 48px 이상) 눈에 잘 띄는 위치에 있습니다.
- [ ] 시작 버튼을 누르면 3초 안에 첫 번째 질문 화면으로 넘어갑니다.
- [ ] 가입·로그인 안내가 전혀 나타나지 않습니다.
- [ ] 모바일 세로 화면에서 가로 스크롤 없이 모든 내용이 보입니다.

### 이야기 2 — 질문 3개로 내 환경 알려주기

시니어 사용자로서, 복잡한 입력 없이 우리 집 환경을 알려주기 위해, 빛·물·목적에 대한 질문 3개를 큰 버튼으로 하나씩 고르는 화면을 원합니다.

**합격 기준**

- [ ] 질문은 빛(밝기), 물(자주 줄 수 있는지), 목적(공기 정화·꽃·선물 등) 순서로 한 화면에 하나씩 나옵니다.
- [ ] 각 답변은 글자로 적힌 큰 버튼(높이 48px 이상)으로 손가락으로 누르기 쉽습니다.
- [ ] 진행 상태("1/3", "2/3", "3/3")가 글씨로 표시됩니다.
- [ ] 답을 고르면 자동으로 다음 질문으로 넘어가고, "이전" 버튼으로 되돌아갈 수 있습니다.
- [ ] 질문 3개를 모두 답하면 추천 결과 화면으로 이동합니다.

### 이야기 3 — 나에게 맞는 식물 3종 추천받기

시니어 사용자로서, 내 환경에 잘 맞는 식물을 빠르게 고르기 위해, 답변에 맞춰 추천된 식물 3종을 사진과 이름, 한 줄 설명으로 보는 화면을 원합니다.

**합격 기준**

- [ ] 답변 조합에 따라 `plants.json`에서 골라낸 식물 정확히 3종이 나타납니다.
- [ ] 각 식물 카드에 사진, 이름, 한 줄 특징("물 적게, 그늘에서도 잘 자람")이 표시됩니다.
- [ ] 추천 결과가 화면에 뜰 때까지 2초를 넘지 않습니다.
- [ ] 각 카드를 누르면 해당 식물의 상세 화면으로 이동합니다.
- [ ] "다시 고르기" 버튼으로 질문을 처음부터 다시 할 수 있습니다.

### 이야기 4 — 식물 상세에서 돌보는 법 보고 구매하기

시니어 사용자로서, 고른 식물을 잘 키우고 바로 구매하기 위해, 큰 글씨 돌보기 안내와 쿠팡 구매 버튼이 있는 상세 화면을 원합니다.

**합격 기준**

- [ ] 상세 화면에 물 주기, 빛, 온도, 주의할 점이 본문 18px 이상 큰 글씨로 나옵니다.
- [ ] "쿠팡에서 구매하기" 버튼이 높이 48px 이상으로 크게 보이고, 누르면 쿠팡 파트너스 링크가 새 창으로 열립니다.
- [ ] 광고임을 알리는 안내 문구("쿠팡 파트너스 활동으로 일정액의 수수료를 받을 수 있습니다")가 표시됩니다.
- [ ] 돌보기 안내는 어려운 한자어 없이 쉬운 말로 적혀 있습니다.
- [ ] "추천으로 돌아가기" 버튼으로 결과 화면으로 되돌아갈 수 있습니다.

### 이야기 5 — 카톡으로 나누고 케어가이드로 다시 찾기

시니어 사용자로서, 마음에 든 식물을 가족·친구와 나누고 나중에 다시 보기 위해, 카카오톡 공유 버튼과 검색으로 찾아올 수 있는 케어가이드 페이지를 원합니다.

**합격 기준**

- [ ] 상세 화면에 "카카오톡으로 보내기" 버튼이 있고, 누르면 식물 이름·사진·주소가 담긴 공유 화면이 열립니다.
- [ ] 각 식물마다 따로 주소(URL)를 가진 케어가이드 페이지가 있습니다.
- [ ] 케어가이드 페이지에는 제목, 설명, 대표 사진이 검색에 잘 잡히도록 들어 있습니다(title·meta description·대표 이미지).
- [ ] 케어가이드 페이지에서도 같은 쿠팡 구매 버튼을 누를 수 있습니다.
- [ ] 공유받은 사람이 링크를 열면 가입 없이 바로 케어가이드 내용을 볼 수 있습니다.

## 3. 성공 지표(Success Metrics)

모두 측정할 수 있는 지표이며, 괄호 안은 출시 후 3개월 목표 예시입니다.

| 지표 | 정의 | 목표 수치(예시) |
| --- | --- | --- |
| 추천 완료율 | 시작 버튼을 누른 사용자 중 질문 3개를 모두 답하고 추천 결과를 본 비율 | **60% 이상** |
| 평균 체류시간 | 한 번 방문에서 사이트에 머문 평균 시간 | **2분 30초 이상** |
| 쿠팡 클릭률(CTR) | 상세·케어가이드 화면을 본 사용자 중 쿠팡 구매 버튼을 누른 비율 | **8% 이상** |
| 재방문율 | 30일 안에 다시 방문한 사용자 비율 | **15% 이상** |
| 케어가이드 SEO 유입 | 검색을 통해 케어가이드 페이지로 처음 들어온 방문자 수 | **월 1,000명 이상** |

측정 방법: 구글 애널리틱스 등 무료 분석 도구의 이벤트(시작·질문 답변·추천 완료·쿠팡 클릭·공유)로 기록합니다.

## 4. 비기능 요구사항(품질 기준)

### 4.1 접근성(시니어 친화)

- 한국형 웹 접근성 지침 **KWCAG 2.2 100% 충족**을 목표로 합니다.
- 본문 글씨는 **18px 이상**, 누르는 버튼은 **높이 48px 이상**으로 만듭니다.
- 글자와 배경의 **명암 대비는 4.5:1 이상**으로 유지합니다.
- 손가락으로 누르기 쉽도록 버튼 사이 간격을 넉넉히 둡니다.

### 4.2 성능

- **라이트하우스(Lighthouse) 점수 90점 이상**(성능·접근성·SEO 기준).
- 첫 화면이 모바일에서 빠르게 뜨도록 이미지 용량을 줄입니다.

### 4.3 구조와 비용

- 서버 없는 **정적 사이트**로 만들어 **운영 비용 0원**을 유지합니다.
- 데이터는 `plants.json` 한 개 파일로 관리합니다.

### 4.4 사용 환경

- **모바일 우선**으로 설계하고 PC에서도 잘 보이게 합니다.
- **가입·로그인·사진 촬영 기능 없이** 누구나 바로 쓸 수 있습니다.

---

## 5. 범위 밖(Out of Scope)

아래 기능은 이번 정적 사이트 범위에 넣지 않습니다.

- 서버 운영 및 데이터베이스(DB) 구축
- 회원 가입·로그인·개인 정보 저장
- 인공지능(AI) 사진으로 식물 알아내기
- 사이트 안에서 직접 결제하는 시스템(구매는 쿠팡 링크로만 연결)
- 사용자가 글·사진을 올리는 커뮤니티·게시판 기능
- 푸시 알림이나 물 주기 자동 알림 기능
- 다국어 지원(우선 한국어만 제공)

---

## 6. 핵심 사용 흐름 요약

1. **시작 화면**: 큰 글씨 안내 + 큰 시작 버튼
2. **질문 3개**: 빛 → 물 → 목적, 큰 버튼으로 하나씩 선택
3. **맞춤 추천**: 답변에 맞는 식물 3종 카드 표시
4. **식물 상세**: 큰 글씨 돌보기 안내 + 쿠팡 구매 버튼
5. **공유·케어가이드**: 카카오톡 공유 + 검색으로 찾는 케어가이드 페이지
