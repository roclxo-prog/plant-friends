# 수익화 전략 — 우리집 초록친구

> 대상은 50~60대 시니어입니다. **신뢰가 곧 수익**입니다.
> 과한 광고·불안 마케팅으로 신뢰를 잃으면 재방문·재구매가 끊겨 장기 수익이 더 나빠집니다.
> 그래서 이 전략의 1원칙은 "**광고는 콘텐츠 하단에만, 결과·도구 위에는 절대 없음**" 입니다.

---

## 1. 수익 모델 (우선순위)

### (주) 쿠팡 파트너스 — 핵심
- 추천 결과·식물 페이지에서 식물·화분·**흙·영양제** 구매 링크 제공 → 구매 발생 시 수수료.
- 시니어 원예 카테고리 수수료는 대략 **~3% 수준**으로 높지 않음 → **건수와 반복구매**로 보완.
- **소모품(흙·비료) 반복구매가 수익의 안정적 기반.** 식물·화분은 1회성, 흙·비료는 분갈이/소진마다 재구매.
- 데이터: `packages/affiliate/coupang-links.json`, 채우기 가이드: `docs/coupang-links-todo.md`.

### (보조) 구글 애드센스
- 콘텐츠 페이지(가이드·식물 상세 등) **하단에만** 광고.
- placeholder 상태에선 광고 미로드. 승인 후 `config.js` 의 ID만 교체하면 자동 작동.
- 체크리스트: `docs/adsense-checklist.md`.

### (옵션) 네이버 쇼핑커넥트
- 국내 시니어는 네이버 쇼핑 친숙도가 높음 → 향후 쿠팡과 병행 가능한 보조 채널.
- 도입 시에도 **배치 원칙 동일**(콘텐츠 하단만). 현재는 미적용, 여지만 남겨둠.

---

## 2. 정직한 기대치

- 트래픽이 없으면 수익도 없습니다. **검색 유입(SEO)·콘텐츠 품질이 선행**되어야 합니다.
- 시니어 원예 객단가·수수료율을 고려하면 **초기 수익은 소액**입니다. 빠른 큰 수익을 기대하면 안 됩니다.
- 현실적 경로:
  1. 콘텐츠 10편+ 확보 → 애드센스 승인 → 검색 색인.
  2. 검색 유입 누적 → 쿠팡 클릭/구매 발생.
  3. **소모품 재구매 사이클**이 돌기 시작하며 누적 수익 증가(수개월 단위).
- 단기 매출보다 **재방문·재구매하는 신뢰 자산**을 쌓는 것이 총수익을 키웁니다.

---

## 3. 광고·링크 배치 원칙 (절대 규칙)

- **결과 화면·도구(quiz/result) 위 광고·배너 절대 금지.** 추천을 보러 온 사용자의 동선을 막지 않습니다.
- 광고·추천 링크는 **콘텐츠가 모두 끝난 하단**에만. (코드가 `.ad-slot` 위치로 강제)
- 자동재생·소리·전면 모달 광고 금지. "광고" 라벨 명시.
- 가격·재고 단정 금지, 클릭베이트 금지(시니어 불안 자극 금지).
- 쿠팡/애드센스 ID는 `config.js` 한 곳에서만 관리, 하드코딩 금지.

> 이 원칙은 단순한 도덕이 아니라 **시니어 신뢰 = 재구매 = 장기 수익** 이라는 사업 논리입니다.
