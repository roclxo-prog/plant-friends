# 우리집 초록친구 — 시니어 친화 UX 가이드 & KWCAG 2.2 체크리스트

> 본 문서는 "우리집 초록친구" 서비스의 **개발자·디자이너 전원이 따르는 시니어 UX 매뉴얼**입니다.
> 50~60대 시니어 사용자의 인지·신체 특성과 한국형 웹 콘텐츠 접근성 지침(KWCAG 2.2)을 함께 반영했습니다.
> 모든 수치는 권장값이 아닌 **최소 기준값**입니다. 더 크게·더 넉넉하게는 허용되나, 더 작게는 금지합니다.

---

## 1. 핵심 원칙 8가지

각 원칙에는 **왜(이유)** 와 **구체 수치**를 함께 적었습니다. 개발 시 그대로 코드에 반영하세요.

### 1) 본문 18px 이상, 제목 24~32px

- **왜:** 50~60대는 노안(노시)으로 가까운 작은 글자의 초점이 흐려집니다. 16px 이하는 읽는 데 피로와 오독을 유발합니다.
- **수치:** 본문 `18px` 이상, 부제목 `24px`, 주요 제목 `28~32px`. 행간(line-height)은 글자 크기의 `1.6배` 이상.

### 2) 명도대비 4.5:1 이상

- **왜:** 노화로 수정체가 황변하면 회색·연한 색의 글자가 배경에 묻혀 보이지 않습니다.
- **수치:** 본문 텍스트 대비 `4.5:1` 이상, 큰 글자(24px 이상 또는 18px 굵게)는 `3:1` 이상. 회색 위 회색 글자 금지.

### 3) 버튼 48×48px 이상, 버튼 간 간격 12px 이상

- **왜:** 손떨림·관절 둔화로 작은 버튼은 오터치가 잦습니다. 버튼이 붙어 있으면 옆 버튼을 잘못 누릅니다.
- **수치:** 터치 타깃 `48×48px` 이상, 버튼·링크 사이 간격 `12px` 이상. 핵심 행동 버튼은 `56px` 이상 권장.

### 4) 한 화면에 1과업(One Task per Screen)

- **왜:** 동시에 여러 선택지가 보이면 인지 부하가 커져 무엇을 할지 헷갈립니다.
- **수치:** 한 화면에는 **주요 행동 버튼 1개**만 둡니다. 보조 동작은 시각적으로 작게·아래에 배치.

### 5) 항상 '← 이전'과 '다시하기' 제공

- **왜:** 잘못 눌러도 되돌릴 수 있다는 안심이 있어야 끝까지 진행합니다. 막다른 화면은 이탈을 부릅니다.
- **수치:** 모든 화면 좌측 상단에 `← 이전` 고정. 결과·진단 화면에는 `다시하기` 버튼 상시 노출.

### 6) 가입·로그인·사진촬영 요구 금지

- **왜:** 아이디·비밀번호 관리, 카메라 권한 허용은 시니어에게 가장 큰 진입 장벽이자 이탈 지점입니다.
- **수치:** 회원가입 `0단계`, 로그인 `없음`, 사진 업로드/촬영 **요구 금지**. 입력은 선택형(버튼)으로 대체.

### 7) 자동재생·팝업 금지

- **왜:** 예고 없이 움직이거나 소리가 나거나 화면을 덮는 요소는 놀람·당황을 유발하고 조작을 방해합니다.
- **수치:** 동영상·소리 자동재생 `금지`, 진입 팝업·광고 모달 `금지`. 안내는 화면 내 인라인 텍스트로.

### 8) 모바일 우선 반응형

- **왜:** 시니어 다수가 스마트폰 세로 화면을 주로 사용합니다. PC를 가정한 좁은 레이아웃은 작동하지 않습니다.
- **수치:** 기준 폭 `360px`(모바일 세로)부터 설계. 가로 스크롤 `금지`, 1열(single column) 레이아웃 우선.

## 2. 시니어 인지 특성 반영 가이드

| 항목 | 적용 방법 |
| --- | --- |
| **짧은 문장** | 한 문장 **15자 이내**. 한 문단 2~3줄. 어려운 한자어·외래어 대신 쉬운 우리말. |
| **그림 + 큰 글씨 병기** | 아이콘·일러스트 단독 사용 금지. 항상 큰 글씨 라벨과 함께 제시(예: 물방울 그림 + "물 주기"). |
| **자연어 비유** | 기능·상태를 일상 언어로. "광량 부족" → "햇빛이 더 필요해요", "관수 주기" → "물 주는 날". 햇빛·물·꽃 같은 친숙한 비유 사용. |
| **진행바 ①②③ 항상 표시** | 여러 단계가 있으면 현재 위치를 `① ② ③` 숫자 원형으로 상단 고정. 현재 단계는 색+굵기+숫자로 강조. |
| **색만으로 정보 전달 금지** | 빨강/초록만으로 구분 금지. 반드시 **텍스트 + 아이콘**을 함께(예: 빨강 + "주의" + 느낌표 아이콘). |

추가 권장:
- 화면 전환 시 변화는 **천천히**(애니메이션 `200~300ms`), 급격한 점프 금지.
- 한 화면의 정보량은 적게. "더 보기"로 점진적 공개.
- 안내 문구는 명령형보다 **권유형 존댓말**("눌러 보세요", "확인해 주세요").

## 4. 금지사항 (절대 X)

아래는 **예외 없이 금지**합니다. 코드 리뷰에서 발견 시 머지 불가입니다.

- **16px 이하 폰트** — 본문·캡션·안내 어디에도 사용 금지.
- **호버(hover) 의존 인터랙션** — 터치 기기엔 호버가 없습니다. 마우스 올림으로만 보이는 메뉴·툴팁 금지.
- **좁은 버튼** — `48px` 미만, 또는 간격 `12px` 미만으로 붙은 버튼 금지.
- **영문 CTA 그대로 노출** — `Submit`, `Next`, `OK` 등 금지. "확인", "다음", "물 주기"처럼 한글로.
- **모달 안의 모달** — 팝업 위에 또 팝업 금지. 원칙적으로 모달 자체를 지양.
- **진행 중 임의 종료** — 사용자 동작 없이 화면이 닫히거나 처음으로 돌아가는 동작 금지.
- **광고를 결과·도구 위 배치** — 진단 결과·핵심 버튼 위나 사이에 광고 삽입 금지. 오터치·혼란 유발.

## 5. CSS 권장 토큰 예시

디자인 토큰을 전역에 정의하고, 컴포넌트는 토큰만 참조하세요. 하드코딩 금지.

```css
:root {
  /* 글자 크기 */
  --font-base: 18px;     /* 본문 최소 */
  --font-caption: 18px;  /* 캡션도 18px 이하 금지 */
  --font-h2: 24px;       /* 부제목 */
  --font-h1: 32px;       /* 주요 제목 */
  --line-height: 1.6;    /* 행간 = 글자 크기 1.6배 */

  /* 색·대비 (모두 4.5:1 이상 확보된 조합) */
  --color-text: #1A1A1A;       /* 본문 (흰 배경 대비 약 16:1) */
  --color-bg: #FFFFFF;
  --color-primary: #1B7A3D;    /* 초록 주색 (흰 글자 대비 4.5:1+) */
  --color-on-primary: #FFFFFF;
  --color-warning-text: #B3261E; /* 경고 텍스트 (반드시 아이콘·문구 병기) */

  /* 터치 타깃 */
  --tap-min: 48px;        /* 버튼 최소 높이·너비 */
  --tap-primary: 56px;    /* 핵심 행동 버튼 */
  --gap-min: 12px;        /* 버튼 간 최소 간격 */

  /* 간격·모서리 */
  --space-1: 12px;
  --space-2: 16px;
  --space-3: 24px;
  --radius: 12px;

  /* 레이아웃 */
  --content-max: 480px;   /* 모바일 우선 1열 최대 폭 */
  --base-width: 360px;    /* 설계 기준 폭 */
}

/* 본문 기본 */
body {
  font-size: var(--font-base);
  line-height: var(--line-height);
  color: var(--color-text);
  background: var(--color-bg);
}

/* 제목 */
h1 { font-size: var(--font-h1); }
h2 { font-size: var(--font-h2); }

/* 기본 버튼: 48px 이상, 한글 라벨, 큰 글씨 */
.btn {
  min-height: var(--tap-min);
  min-width: var(--tap-min);
  padding: 0 var(--space-3);
  font-size: var(--font-base);
  border-radius: var(--radius);
  background: var(--color-primary);
  color: var(--color-on-primary);
  border: 0;
  cursor: pointer;
}

/* 핵심 행동 버튼: 한 화면 1개, 더 크게 */
.btn--primary {
  min-height: var(--tap-primary);
  font-size: var(--font-h2);
  width: 100%;
}

/* 버튼이 모일 때 최소 간격 강제 */
.btn-group { display: flex; flex-direction: column; gap: var(--gap-min); }

/* 모바일 우선 1열 레이아웃 */
.container {
  width: 100%;
  max-width: var(--content-max);
  margin: 0 auto;
  padding: var(--space-2);
}

/* 호버 의존 금지: 포커스도 함께 처리 */
.btn:hover,
.btn:focus-visible {
  outline: 3px solid var(--color-primary);
  outline-offset: 2px;
}

/* 자동 움직임 최소화 */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
```

```html
<!-- 진행바 ①②③ 예시: 색만이 아니라 숫자·텍스트 병기 -->
<nav aria-label="진행 단계">
  <ol class="steps">
    <li aria-current="step">① 식물 고르기</li>
    <li>② 상태 확인</li>
    <li>③ 돌보는 법</li>
  </ol>
</nav>

<!-- 그림 + 큰 글씨 병기, 한글 CTA -->
<button class="btn btn--primary" type="button">
  <img src="/img/water.svg" alt="" aria-hidden="true" />
  물 주기
</button>
```
