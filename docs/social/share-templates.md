# 공유 글 템플릿 — 카톡 · 밴드/카페

> 톤: 따뜻함·존댓말·짧은 문장(`docs/brand.md`). 도배·스팸·클릭베이트·허위효능 금지.
> 모든 글은 "먼저 도움이 되고, 도구는 자연스럽게" 원칙. 광고처럼 보이면 차단됩니다.

---

## 1. 카카오톡 공유 메시지

### 1-1. 자녀에게(부모님이 받았을 때 자녀에게 보내는 톤 / 또는 자녀가 부모님께)
```
엄마, 이거 질문 세 개만 누르면 우리집에 맞는 식물 골라줘요.
가입도 사진도 필요 없어요. 한번 해보세요 🌱
[링크]
```

### 1-2. 친구·또래에게
```
○○님, 키우기 쉬운 식물 찾고 계셨지요?
여기서 질문 3개 답하니까 우리집에 맞는 친구 알려주네요.
물 자주 안 줘도 되는 걸로요 :) [링크]
```

### 1-3. 결과 페이지 공유(추천 결과를 받은 뒤 자랑/추천)
```
저는 '스킨답서스'가 나왔어요 🌿
빛 약한 우리집에도 잘 맞는대요. ○○님은 뭐 나오는지 해보세요.
[결과 링크]
```

> **OG 미리보기 활용**: 결과/사이트 링크를 카톡에 붙이면 미리보기 카드(제목·설명·이미지)가 자동으로 뜹니다.
> - 카드 제목/설명은 `result.html`·각 페이지의 `og:title`/`og:description`로 노출됩니다.
> - OG 이미지(`/public/og-image.png`, 1200×630)는 크림 배경 + "실수해도 괜찮아요. 당신의 첫 식물 친구" 한 줄(브랜드 가이드 5-3).
> - 카드가 떠야 클릭률이 오릅니다. 배포 후 `KAKAO_JS_KEY`(`scripts/config.js`)와 절대 URL을 실제값으로 교체하고, **카카오 공유 디버거**로 미리보기가 정상인지 1회 확인하세요.
> - 텍스트만 길게 붙이지 말고, **한두 줄 + 링크**가 가장 잘 열립니다.

## 2. 네이버 밴드 / 카페 글 (시니어 톤, 도배 금지)

> 원칙: ① 먼저 활동(댓글·인사·내 식물 사진)으로 신뢰를 쌓고 ② 질문/고민 글에 **도움 답변** 형태로 ③ 도구는 "이런 것도 있더라" 정도로 가볍게. 같은 글 복붙·여러 카페 동시 도배 금지(스팸 차단 사유).

### 글 예시 ① — "내 경험 나눔" (가장 자연스러움)
```
제목: 처음 키운 산세베리아, 반년째 잘 살아요 :)

안녕하세요. 식물은 처음이라 늘 죽이기만 했는데,
물을 자주 안 줘도 되는 산세베리아는 반년째 잘 자라네요.
빛 약한 거실에서도 괜찮았어요.

저처럼 처음이신 분들은 물 자주 안 줘도 되는 걸로 시작하시면 마음이 편해요.
혹시 우리집에 뭐가 맞을지 모르겠으면, 질문 몇 개 답하면 골라주는 곳도 있더라고요.
필요하신 분 계시면 댓글로 알려드릴게요.
```

### 글 예시 ② — 질문 글에 다는 답변(댓글)
```
저도 처음에 같은 고민이었어요.
빛이 약한 방이면 산세베리아나 스킨답서스가 잘 맞아요. 물도 자주 안 줘도 돼요.
'우리집 초록친구'라고 질문 3개 답하면 맞는 식물 골라주는 곳에서 저는 스킨답서스가 나왔는데 잘 키우고 있어요. 가입도 사진도 필요 없어요 :)
```

### 글 예시 ③ — 케어 팁 나눔(정보 제공형)
```
제목: 식물 물주기, 저는 이렇게 하니 안 죽더라고요

물을 정해진 날짜에 주는 것보다, 흙을 손가락으로 눌러보고
말랐을 때 한 컵 정도만 주니까 훨씬 잘 자라요.
잎이 조금 시들어도 며칠 말려주면 다시 괜찮아지더라고요.

식물별로 물주기·햇빛 정리해 둔 글도 봤는데 도움이 됐어요.
처음이신 분들 너무 어렵게 생각 안 하셔도 돼요. 천천히 같이 키워봐요.
```

> ②③에서 링크는 **요청이 있을 때 댓글로** 또는 카페 규정상 허용될 때만. 본문에 링크 도배 금지.

## 3. 차단 회피(=신뢰 유지) 체크리스트
- [ ] 같은 문장 복붙 금지 — 글마다 다르게, 내 경험을 넣어 씁니다.
- [ ] 가입 직후 글쓰기 금지 — 먼저 며칠간 댓글·좋아요로 활동합니다.
- [ ] 한 글에 링크 1개 이하, 본문 상단 링크 지양.
- [ ] 카페·밴드별 광고/홍보 규정 먼저 확인(위반 시 강퇴·신고).
- [ ] 효능 단정·과장 금지("미세먼지 다 없앤다" 류 금지 — `허위효능`).
- [ ] 존댓말·짧은 문장·따뜻한 마무리("천천히 같이 키워봐요").
