# 식물 사진 출처 큐레이션 (12종)

> 모든 사진은 **CC0 또는 무료 상업 이용 가능** 라이선스만 사용합니다.
> 저작권/출처 불명 이미지는 절대 금지합니다.
>
> **라이선스 요약**
> - **Unsplash**: 무료 상업 이용 가능, 저작자 표시(크레딧) 의무 없음(권장).
> - **Pixabay**: Pixabay Content License, 무료 상업 이용 가능, 저작자 표시 불필요.
> - **Pexels**: 무료 상업 이용 가능, 저작자 표시 불필요(권장).
>
> 다운로드 후 실제 사용한 사진의 작가/URL을 `docs/asset-licenses.md`에 반드시 기록하세요.

## 사용 방법
1. 아래 검색어/후보 URL에서 4:3 비율에 가까운 식물 단독 사진을 고릅니다.
2. `public/plants/{id}.jpg` 파일명으로 저장합니다(예: `public/plants/sansevieria.jpg`).
3. 권장 규격: 가로 800px 이상, 4:3 비율로 크롭, JPG 품질 80 내외.
4. 사진이 아직 없을 때는 `public/plants/placeholder.svg`가 자동 폴백됩니다.
