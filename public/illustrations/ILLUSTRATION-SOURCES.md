# 일러스트 출처 큐레이션 (시니어 친화)

> 히어로/안내용 일러스트는 **무료 상업 이용 가능** 출처만 사용합니다.
> 50~60대 시니어가 편안함을 느끼는 따뜻하고 둥근 스타일을 우선합니다.
> 실제 사용한 일러스트의 작가/URL/라이선스는 `docs/asset-licenses.md`에 기록하세요.

## 라이선스 요약
- **Storyset (Freepik)**: 무료 이용 가능. **단, 무료 플랜은 저작자 표시(Attribution) 필수** — 페이지/푸터에 "Illustrations by Storyset" 크레딧 링크를 넣어야 합니다. 브랜드 컬러(`#2E7D32` 초록, `#5D4037` 브라운)로 색상 커스터마이즈 후 SVG/PNG 다운로드 가능.
- **unDraw**: 오픈 라이선스(MIT 유사), **무료 상업 이용 + 저작자 표시 불필요**. 사이트에서 메인 컬러를 브랜드 초록 `#2E7D32`로 지정해 다운로드하면 톤이 통일됩니다.
- **Pixabay**: Pixabay Content License, 무료 상업 이용 가능, 저작자 표시 불필요.

> 권장: 크레딧 의무가 없는 **unDraw**를 1순위로, 색 커스터마이즈가 강력한 **Storyset**을 보조로 사용(크레딧 표기 조건 준수).

## 사용처별 추천

### 1) 히어로(첫 화면) — 식물과 함께하는 따뜻한 장면
- **권장 파일명**: `public/illustrations/hero.svg`
- **추천 검색어**: gardening, plants, taking care of plants, elderly people
- **후보 출처**:
  - unDraw 검색: https://undraw.co/search (검색어 "gardening", "plants", "nature") — 크레딧 불필요, 1순위
  - Storyset 정원/원예: https://storyset.com/gardening — 크레딧 필요
  - Storyset 시니어: https://storyset.com/elderly — 크레딧 필요
  - Pixabay 일러스트: https://pixabay.com/illustrations/search/gardening/ — 크레딧 불필요
- **사용처**: 메인 랜딩 히어로 영역. 초록 `#2E7D32` 위주로 커스터마이즈.

### 2) 빈 결과 화면 — 추천 결과가 없을 때
- **권장 파일명**: `public/illustrations/empty.svg`
- **추천 검색어**: empty, no data, searching, void
- **후보 출처**:
  - unDraw 검색: https://undraw.co/search (검색어 "empty", "void", "searching") — 크레딧 불필요, 1순위
  - Storyset: https://storyset.com/ (검색어 "empty state") — 크레딧 필요
  - Pixabay 일러스트: https://pixabay.com/illustrations/search/empty/ — 크레딧 불필요
- **사용처**: 조건에 맞는 식물이 없을 때. "조건을 조금 바꿔볼까요?" 카피와 함께. 차갑지 않고 부드러운 톤 선택.

### 3) 완료 화면 — 추천/저장 완료
- **권장 파일명**: `public/illustrations/done.svg`
- **추천 검색어**: completed, done, celebration, success, watering plant
- **후보 출처**:
  - unDraw 검색: https://undraw.co/search (검색어 "completed", "celebration", "well done") — 크레딧 불필요, 1순위
  - Storyset 원예: https://storyset.com/gardening (물주기/돌봄 장면) — 크레딧 필요
  - Pixabay 일러스트: https://pixabay.com/illustrations/search/success/ — 크레딧 불필요
- **사용처**: "다 됐어요. 잘 저장해 두었어요." 완료 안내. 밝고 안심되는 분위기.

## 톤 & 적용 메모
- 모든 일러스트는 **브랜드 초록 `#2E7D32`**을 주조색으로 통일(unDraw/Storyset 모두 색상 지정 가능).
- 둥근 곡선 위주, 날카로운 각 지양(브랜드 가이드 5.2 참고).
- Storyset를 사용할 경우 **사이트 푸터에 크레딧 링크 필수**. 크레딧을 넣기 어려우면 unDraw/Pixabay만 사용.
