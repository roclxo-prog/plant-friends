## 사용 팁

- **카카오톡/밴드 피드**: `share-card-main.png` 또는 주제 카드(air/petsafe)를 그대로 첨부.
- **인스타그램 피드**: 1080x1080 정사각 3종이 그대로 맞습니다.
- **카톡 링크 미리보기**: 사이트 OG 태그가 우선이지만, 가로 보조 이미지가 필요하면 `kakao-link.png`.
- **유튜브**: `youtube-thumb.png`(1280x720)를 썸네일로 업로드.

## 제작 정보

- 제작 방식: SVG 작성 → `sharp`로 PNG 변환(자체 스크립트, 작업 후 임시 SVG/스크립트 정리).
- 한글 폰트: 렌더 환경의 시스템 산세리프(Malgun Gothic) 사용. 브랜드 기준 폰트는 Pretendard / Noto Sans KR.
- 라이선스: 자체 제작 · 브랜드 소유(독점). 자유롭게 사용 가능. (`docs/asset-licenses.md` 참조)
- 수정/재생성이 필요하면 동일한 방식(SVG → sharp)으로 다시 만들면 됩니다.
